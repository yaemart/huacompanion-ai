# 本地亲测：公开订阅提交与邮件队列（H 2.2b）

匿名访客可通过提交接口明确同意当前隐私版本，并选择主题。单场展会只接受对应语言中仍可订阅的已发布展会。成功、同邮箱限额和蜜罐命中使用相同的接收回执。回执表示请求已处理，发件结果由后续 worker 记录。

同一邮箱会先规范大小写和首尾空格。跨主题共用 15 分钟入队间隔，任意连续 24 小时最多排入五份单封确认邮件。独立的客户端和全站限额保护提交端点。非本机运行须经可信网关。

## 在 Mac 上亲测

同步代码，使用仓库指定的 Node 24.22.1。按[本地测试指南](local-testing-guide.md)启动演示环境，保持数据库运行。另开终端，在项目目录执行

```sh
npm run test:subscriptions
```

看到四条 `PASS` 即通过。第四条验证公开提交、同邮箱并发去重、入队冷却、滚动上限、队列回滚及匿名读取限制。命令会在独立临时库应用迁移、拦截外部请求，并在测试后清理。现有演示资料可直接沿用。

`20261117_210000_subscription_mail_queue` 新增一张私有待发送表。新增 `SUBSCRIPTION_REQUESTS_ENABLED`，默认关闭，可在保留既有确认和退订链接时关闭新提交。亲测命令会临时配置虚构发件资料与开关。

下一批消费这张队列表，验证单封邮件的可靠重试、发送时间限额和邮箱客户端一键退订。当前验收截止到入队，真实邮件发送为零。群发留在停止点 C。
