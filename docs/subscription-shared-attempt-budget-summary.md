# 本地营销、确认和资料邮件共用尝试预算

本地模拟营销现在与确认/资料邮件共用同邮箱15分钟间隔、滚动24小时最多5次尝试，跨主题统计。营销只在“开始本地尝试”计次，领取、等待和重复核实不多计；完成、失败和结果不明都保留消耗。营销占位的邮箱归属冻结，后来修改联系方式不会转走已消耗次数。真实发件没有因此开放。

## 页面亲测

管理员准备虚构余额并授权，主管保存、模拟确认、冻结并占位。若同邮箱刚有确认/资料尝试，领取或开始会显示“等待同邮箱共用冷却或尝试预算”，给出下次时间；未开始可显示0次。页面会丢弃原领取凭证，冷却后需要重新领取，原60秒未开始租约到期可恢复。

调度会跳过等待邮箱，其他邮箱仍可处理。临时失败/429同时取原退避和共用限制的更晚时间，原任务最多5次/首次起23小时仍有效，超时或结果不明停待核对，没有清除入口。开始成功后丢失回执，仅用原请求核实，仍返回原次尝试，不会因自身冷却另记一次或改成等待。原角色、额度、来源与暂停取消规则保持。
