# 单展会日历下载：一页小结

[草稿PR121](https://github.com/yaemart/huacompanion-ai/pull/121)。用户接受整届一个全天日程，分期写入说明；本批为展会详情补上`.ics`下载。

- 读者可下载已公布、日期完整的展会，导入自己的日历；最后一天完整保留，已结束展会可作历史日程。待公布、延期、取消及日期不完整时显示不可下载说明。
- 文件包含名称、日期、场馆和地址、概要、分期、详情网址、官方来源与核实日期。中英及其他五语言入口独立，沿用原审核发布；未审核草稿不进入文件，撤下后不可下载。
- 这是一次性导入，改期需重新下载；稳定日程编号不等于各厂商客户端保证自动覆盖。文件不设提醒或邀请，用户日历本身的默认提醒仍由其设置决定。
