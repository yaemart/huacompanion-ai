已取消活动的政策来源变化、下架或过期时，页面说明旧预览仅供查阅。

## 本机亲测

使用 Node24.22.1，保持演示数据库运行，执行：

```sh
npm run test:subscriptions -- --preview --isolated-browser
```

现在每次会先在临时副本中执行生产构建，再启动3186预览。请等终端显示构建完成和
服务器 Ready 后，打开 `http://localhost:3186/admin/login`。首次等待时间包含完整构建。
修改代码后重新运行预览以载入新版本。日常 `npm run dev` 保留 Fast Refresh。

预览中的德国 DE 政策名称明确标为虚构隔离资料，来源为 `example.invalid`，仅供测试。
样例使用生产校验支持的国家代码；正式政策及本机3100演示资料保持原有数据。
使用终端指定的临时账号，管理员授权主管后换主管新建活动、保存、取消并刷新，
应保持已取消及历史快照。来源失效时应只提示查阅历史。

按 Ctrl+C 退出后清理本次临时库、账号和构建副本。构建失败也会清理，需根据错误重启。
原数据库和图片无需 reset，本批没有数据库迁移、依赖或产品环境变量变化。
