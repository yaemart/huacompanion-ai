# 受控本地调度循环：设计小结

PR127已合并，main a193600包含1B最终16ae13a。本批先设计循环、私有运行目录和信号停止，正式文档见[设计](superpowers/specs/2026-11-27-exhibition-reminder-loop-design.md)。尚未实施或启动调度，真实发送继续后批。

沿原生前台串行与现有命令入口，管理员固定1–20个本届＋语言，私有16KiB清单；立即一轮，完成后60秒再跑，等待期间最长5秒发起身份复查。会话过期、登出、停用或撤权停止；原数据库北京时间30/7窗口、不补旧日、审核、写锁、持久恢复和H真实试发门禁保持。

用户已选每次新建独占运行目录。目录0700、文件0600，不复用/覆盖旧目录或自动清历史。运行元数据/清单绑定、原回执和各阶段只追加；文件、发布和包含目录同步确认后才应用。旧目录只留证，换目录不绕过数据库pending。面向可验证uid/NOFOLLOW/目录同步的本地macOS/Linux环境，不虚构不支持文件系统的持久保证。

拟用`exhibition:reminders -- schedule --auth-file PATH --manifest-file PATH --state-dir NEW_PATH [--once]`，具体命令会在实施计划固定。--once执行同一真实单轮本地待发流程，不是只读预演。运行中改输入文件不换身份/范围。无变化轮次不写文件/心跳审计，正常开始/停止的控制审计另计。

每个有变化目标：只读预检→原回执/计划元数据持久保存→原prepare确认pending→阶段保存→原session.apply→明确成功后finish→完成阶段保存。任何失败/未知整次停止，不重试、不换封套、跳目标或同会话自恢复；新恢复会话按原status/inspect/resolve核实。

SIGINT/SIGTERM唤醒等待并停止新工作；已批准事务可按原规则完成，仍有效授权时仅做该操作的正常收尾。身份失效不补停止审计，已有pending留给独立恢复。finish已实际提交而响应/本地保存丢失时，DB可能已无pending；本进程仍停止核实，不假报全库阻断或自动续跑。只关闭自己的资源，不强杀其他网站/worker。

一次独立可实施性检查无重要未决问题，无额外问答。实施者提出的细节包括：只追加阶段文件/每元数据16KiB、目录同步、非秘密端点摘要与DB关联双重核实、沿现有命令增加schedule、--once及130/143停止退出码。设计已由用户接受，三份顺序实施计划已写待审：私有目录库→受控--once及信号→连续循环；每批验收合并后再下一批；按实际源码预算分顺序增量，每批独立验收，不自动合并。

本轮只有设计/交接文档。检查结果在交接记录和PR中实核；未跑新循环PG/信号/构建或声称自动调度验收。无依赖/迁移/.env/原库变化，五份无关草稿保留，原始日志仅本机.local/exhibition-reminder-loop-design未上传。
