# 咨询关闭与重开

后台咨询的「处理操作」区保留两个字段。「处理状态」记录业务结果，「协调进度」记录正在做什么。平时可以分别选择后点顶部「保存」。

- **关闭**。任一字段选「已关闭」，填写原因后点「确认关闭」。两项同时关闭，审计记录保留操作者、时间、两项前后值和原因。点「取消」可返回原值。
- **重开**。点「重开咨询」，分别选择重开后的处理状态、协调进度，填写原因再确认。有其他修改时先点顶部「保存」。
- **协调完成**。把协调进度设为「已完成」并保存，界面会提示「协调已完成，成交状态另行确认」。成交统计仍采用明确的成交状态或客户报价确认。
- **旧记录**。原先只有一项关闭的咨询会提示「请核对状态」，两项原值可见。可补齐关闭或明确重开。联系人等资料仍可编辑。

## 本轮可以测的场景

对应清单 **E7** 的咨询处理部分。普通启动演示站后，用运营账号打开自己负责的 `DEMO-INQUIRY-2`。

1. 先记下处理状态。将协调进度改成「已完成」，保存并刷新，核对处理状态和提示。
2. 从协调进度选择「已关闭」，核对空原因时不能确认，取消后原值保留。再从处理状态关闭，填写虚构原因并确认，刷新后两项均显示「已关闭」。
3. 点「重开咨询」。分别选择新的处理状态和协调进度，填写虚构原因，确认后刷新核对。管理员可在审计记录中查看两次操作的前后值及原因。

普通重启即可使用，无需重置或迁移。E7 的报价费用项和 E8 的主管毛利、报价二审仍排在任务 F。新人独立计时与实体手机体验由本地测试者记录。 [本地测试清单](tasks/local-test-checklist.md)
