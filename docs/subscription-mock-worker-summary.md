# 本地模拟营销独立 worker

PR105合并后，已从最新main `02bec32` 接入专用命令，[PR106](https://github.com/yaemart/huacompanion-ai/pull/106)。
用户已选择指定主管、活动版本和模拟结果，只处理已有占位。管理员准备余额和主题授权、主管在后台保存、模拟确认、冻结和占位后，
另开终端运行；以下编号是虚构示例，替换为本机获授权主管及本人当前活动：

```sh
npm run subscriptions:mock-worker -- --staff 7 --campaign 00000000-0000-4000-8000-000000000001 --revision 1 --once
```

去掉 `--once` 则持续核对，每轮最多处理一项。默认结果为虚构完成；可指定 `--outcome temporary`、
`rate-limited`（可加 `--retry-after-ms 120000`）、`unknown` 或 `permanent`。
每次启动固定一种结果，不随机改变、不调用真实发件。`--once` 只执行一轮，可能返回空闲/等待，不保证完成一项。

worker串接原候选、领取、开始和结果服务，每阶段复核权限、本人活动版本、确认、资格及暂停取消。
原余额、占位、北京日2000份、邮箱24小时1份、共用15分钟/24小时5次、全站1秒、确认资料优先和重试规则保持。
本命令不准备余额或占位，不代确认，也不消费优先单封邮件；若有可处理确认/资料，需原模拟流程处理后继续。
等待不计次；短时调度等待保留原未开始凭证且不续期，确定的开始前租约失效则下轮重新选择。

`idle-local` 表示本轮无可领任务，可能仍在等共用尝试预算、冷却或优先邮件；有时间时返回下次不早于时间。
`completed-local` 只代表模拟完成；`retry-local` 沿用原退避及共用冷却；`review-local` 不开放清除。
权限、结果或提交异常会停机，不补造成功；已开始但结果不明的任务，重启不能接管或重置。
Ctrl+C/TERM停止后续轮次，进行中的操作仍可能已提交，应通过原状态汇总核对；强制终止后沿用原租约/review规则。
