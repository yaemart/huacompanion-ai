# 内容质量复核

入口 `/quality-center`；仅显示员工已获授权的内容板块。审核员或管理员可登记复核，负责人必须启用并具有对应内容板块权限。

每次登记要求当前修订号、已有来源编号、复核依据、负责人和未来复核日期。保留独立复核事件，不把资料完整度等同事实认证、资质认证或发布许可。复核动作不会发布、改写或下架任何正式快照。

内容稿发生实际正文变更时，将本稿以及明确通过 sourceDraft 关联、相同 contentKey 和 kind 的译文标记待复核。仅审核状态改变不会触发失效。译文登记复核时记录原稿内容指纹；独立维护语言不会自动关联或改写。覆盖表包含七种语言。

`runQualityReview(payload)` 为到期或待复核内容创建站内工作流提醒，以稿件、正文指纹、上次核对及下次核对日期去重；无合格负责人时跳过。无邮件或付费模型调用。调度由部署环境显式安排。

公开展示只能调用 `publicQualityMetadata(metadata, publishedRevision)`：仅对本次被核对的发布版本返回核对时间与下次复核时间，不返回负责人、内部依据或来源选择。`qualityStatusLabel(locale, metadata)` 提供七语言提示。新的草稿复核不能给旧版正式内容添加新复核声明。既有展会过期、机构和服务业务门禁保持独立。

本地集成验证：`APP_ENV=local npx tsx tests/integration/quality.ts`。使用本地测试数据库，执行前应完成集合注册和迁移。
