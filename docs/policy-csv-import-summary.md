# 本地亲测：批量导入政策（任务 G）

有政策编辑权限的员工可以在「政策共用事实」下载空白 CSV。每行生成一份共用事实草稿，填写的中英文说明各自保存为草稿。导入记下操作人，核实人默认取当前登录账号。事实和语言说明分别沿用原来的审核流程。

## 用虚构资料亲测

1. 合并后按[本地测试指南](local-testing-guide.md)启动演示站。用运营账号打开[政策共用事实](http://127.0.0.1:3100/content-center/policy-facts)，展开「批量导入政策 CSV」，下载空白模板。此批无需重置演示数据或执行新迁移。
2. 在表头下粘贴下面两行，保存为 UTF-8 CSV。点击「检查 CSV」。第 3 行的国家代码应报错，并且整批没有写入。

   ```csv
   XZ,240小时过境,240,小时,2026-01-01,,虚构过境口岸,https://example.invalid,2026-01-01,仅用于演示,Demo only,,xz-local-csv-practice
   ZZ,其他,30,天,2026-01-01,,,https://example.invalid,2026-01-01,,,,zz-local-csv-practice
   ```

3. 删除第二条数据，重新选择文件并检查。点「导入为草稿」，打开生成的记录，确认显示「草稿；未发布」，停留为 240 小时，来源、核实日和中英文说明对应。重复检查同一份文件，应提示政策标识已存在。
4. 可接着测清单 **E1–E4** 的政策草稿与审核环节。运营可手动送审，审核人可退回并填写原因，运营改完重新送审，审核人发布。运营无法自审，纯审核账号没有导入入口。只做导入时，**C1–C3** 的公开查询结果沿用已发布事实。

请保留表头。日期用 `YYYY-MM-DD`，多个口岸写在同一单元格内，每行一个。截止日、中英文说明、内部备注和内容标识可留空。同一国家和类型有多条不同政策时，需要填写各自的内容标识。每次最多 200 行、250 KB。

已用当前结构的空白 CSV 跑通浏览器流程。仍需《首批免签政策录入与核实模板》的空表或第一行表头，才能核对原表导出的 CSV 是否能直接导入。真人独立计时留待本机亲测。
