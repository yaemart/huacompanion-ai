# 内容标识与「高级」区：本地验收

打开[内容工作台](http://127.0.0.1:3100/content-center?kind=guide)，以运营账号用虚构资料测试：

1. 新建来华指南，只填标题及原有必填内容，直接点「保存草稿」。
2. 展开「高级」，确认系统已生成内容标识和网址标识。纯中文标题会得到类似 `guide-4f8c71a2` 的网址。
   改标题并保存，两个标识应保留。普通未发布稿仍可在这里更换网址；曾发布的网址锁定。
3. 新建另一篇同语种、同英文标题的指南。网址应自动加后缀；主动手填已占用的标识时应提示冲突。
4. 新建网站页面时先明确选择首页、隐私等页面。同语种已存在时应打开原稿；同页旧标识可沿用，不能换绑另一固定页。

标题相同不会自动把两篇普通内容配成双语版本。需要沿用现有标识时，可在首次保存前在「高级」填写。
审核、发布、AI 转写和政策工作台照原流程。本机 3100 刷新即可验收，不需重置、迁移或新增环境变量。
