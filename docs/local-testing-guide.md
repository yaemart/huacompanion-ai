## 启动、关闭、重置

在项目目录执行；Mac也可双击根目录`start.command`。第一次先安装Node24.22.1和PG15或16（如`brew install postgresql@15`）；缺npm依赖自动`npm ci`。启动器不购买、不自动安装数据库，不自动升级已有PG大版本。特殊安装用`PG_BIN=/匹配版本/bin`。

| 操作     | 命令                  | 结果                                                                                 |
| -------- | --------------------- | ------------------------------------------------------------------------------------ |
| 启动     | `npm run local:start` | 检查环境，首次建专用库并跑既有迁移、载入演示、启动并打开浏览器；以后保留修改         |

| 恢复初始 | `npm run local:reset` | 输入`RESET`；先备份专用库和图片到`.local/backups/demo-*`，再重建；你的测试修改会清除 |

## 临时用同一Wi-Fi手机访问

只在可信的私人Wi-Fi使用，手机和Mac连同一个网络。先`npm run local:stop`，再`npm run local:start -- --lan`；把终端显示的`http://192.168...:3100`或其他私网网址输入手机，不能用手机的127.0.0.1。Mac防火墙若询问，仅在该可信网络允许Node入站；访客网络隔离或VPN可能使地址不可达，不要关闭整机防火墙。

此模式只绑定选中的私网地址；本机也用该显示地址。HTTP无加密，只用随机演示账号和假资料，不输入护照或真实客户信息，不分享密码、不转发端口、不接公网隧道。用完`npm run local:stop`，再普通`npm run local:start`恢复仅本机；Wi-Fi换地址后先停再开。手机关Wi-Fi转移动数据无法访问私网，C10真实网络计时留部署后，桌面缩放/限速不算真机结果。
