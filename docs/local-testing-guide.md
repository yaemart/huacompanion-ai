# 华伴本地测试指南

先把本地体验做好，由你亲测后再考虑部署；11月30日不再是上线日期。只用虚构资料，AI、邮件、语音、通话保持关闭。

## 启动、关闭、恢复初始数据

在项目目录打开终端执行；也可双击根目录 **华伴演示.command**，按菜单操作。

| 操作         | 命令                 | 结果                                                                |
| ------------ | -------------------- | ------------------------------------------------------------------- |
| 启动         | `npm run demo`       | 自动启动独立数据库与网站；第一次装入演示数据，以后保留修改          |
| 关闭         | `npm run demo:stop`  | 只关闭演示网站与数据库；关闭终端窗口不会自动停站                    |
| 恢复初始状态 | `npm run demo:reset` | 输入`RESET`确认；先配套备份，再重建演示库并重新启动，测试修改将清除 |

官网：<http://127.0.0.1:3100/zh>；后台：<http://127.0.0.1:3100/admin>。可在浏览器地址栏把`zh`改为`en`看英文。

这台Mac已有运行环境。新电脑先安装`.nvmrc`指定的Node24.22.1与PostgreSQL15；启动器会检查版本，缺少npm依赖时执行`npm ci`。PG工具默认从Homebrew查找，也可设置`PG_BIN`为PG15的bin目录。缺环境时按提示处理，不会自动安装数据库或修改系统服务。

## 四个测试账号

邮箱和本机随机密码在`.local/demo/accounts.txt`。Mac可执行`open -a TextEdit .local/demo/accounts.txt`查看。密码不在Git里，不要截图或转发凭据。重置数据后仍使用这份凭据。切换账号时先在后台退出再登录；它们的登录Cookie与原3000站隔离。

| 账号                          | 可以测什么                                    | 应当被拒绝的操作                              |
| ----------------------------- | --------------------------------------------- | --------------------------------------------- |
| admin 管理员                  | 全部演示内容、员工、业务设置                  | 自审未填写管理员例外原因                      |
| manager 主管                  | 团队3条咨询、服务单、报价及内部成本           | 未获内容审核角色时发布内容                    |
| operations 运营（兼内容编辑） | 本人2条咨询与报价；编辑政策、指南、展会并送审 | 查看其他负责人/未分配咨询、查看成本、审核发布 |
| reviewer 审核人               | 审核政策、指南、展会，退回修改或发布          | 编辑权限之外的写入、业务咨询与成本            |

## 从哪里开始测试

- 政策：后台“内容工作台”→“入境政策”，或直接访问`/content-center?kind=immigration-policy`。有已发布及待审的中英虚构政策；公开工具在`/zh/tools/china-visa-free-checker`。所有国家和来源均为演示，不能用于出行。
- 指南、展会：在内容工作台选择对应类型，或浏览`/zh/guides`、`/zh/exhibitions`。各2条、各有中英版本；第一条已发布，第二条待审核。
- 业务：后台“客户咨询”有3条，`/business-center`有2个服务单及2份草稿报价。用主管与运营对照检查成本和数据范围。
- 典型闭环：运营修改已发布示例并保存、提交审核→退出→审核人登录、退回或发布→到前台核对。需修改待审核稿时，先由审核人退回。

## 发现问题怎么记录

每个开发PR合并后，先拉取最新main，关闭再重新启动演示（刷新代码、保留数据）；若需要全新场景，再恢复初始状态。启动后再打开页面，避免旧页面的过期登录或未保存内容。

反馈格式：**代码提交/PR、使用账号、页面地址、操作步骤1/2/3、预期结果、实际结果、截图**。截图遮住密码和私人资料。标明是否刚重置；先保留问题现场，别急着重置。

数据、图片、日志、重置前备份均在`.local/demo/`，不覆盖原`.env`、55438数据库和图片；3100/55442端口占用会提示，不会关掉其他程序。启动器或环境失败先看`control.log`，装入数据失败看`seed.log`，网站失败看`web.log`，修复后重试；首次建库中断的残留会先保留再重建，已完成库异常则保留现场、不要删状态文件；若提示已有操作进行，等启动完成后再操作。日志和账号文件不上传Git。
