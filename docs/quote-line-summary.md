# 报价费用项主体和分项成本

服务单的「新建报价版本」里可以选用新版费用项。每项可选择华伴自营、权限内已核实或已签约的服务商，或通过「例外」手填服务方。

- 华伴自营采用「华伴统筹」，三方名称取后台公司主体。公司主体为空时，草稿会显示待补。
- 名单或手填服务方采用「合作对接」，签约方和收款方随服务方带入。每个草稿版本保存当时的名称，后续改名不会改写旧版本。
- 主管和管理员可以填写同币种的「本项成本合计」。空值显示「待补成本」，明确填写 0 显示 0.00。运营可见三方主体，成本字段只在主管或管理员权限内显示。

## 本轮可以测的场景

1. **E7 费用项。** 用运营打开 `DEMO-INQUIRY-2` 的服务单，展开「新建报价版本」并勾选新版费用项。试选名单内服务商或填写虚构手填名称，保存后核对服务方、签约方和收款方。
2. **E8 成本权限。** 用同组主管另建新版草稿，加两条费用项，一条成本填 0，一条留空。保存后刷新。换运营打开同一服务单，仍能看到三方主体，成本栏隐藏。旧报价的原总成本继续由原角色查看。

新版费用项本批可保存草稿。代收、主体差异逐项确认、旧草稿另存新版、对客展示和毛利视图随 F 后续批次。旧版报价继续走现有二审，旧数据和原总成本保留。真人新人计时和实体手机待验。
