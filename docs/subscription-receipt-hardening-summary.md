# 本地续发收据与预检说明补强

后台核实续发收据时，现在会关联原名单实际冻结的草稿，检查原版号、负责人和活动。原冻结第2版、当前第3版时，写成第1版的损坏收据也会拒绝；查询不修复记录，不改变任务、尝试、租约或审计。来源和邮件配置变化不影响查阅合法历史，执行时仍须重新通过原有检查。

收据查询只读取获授权的当前活动元数据和收据，不再读取订阅名单。没有原快照或仍是原冻结版本的页面跳过收据查询。原草稿预览仍会读取当前资格人数，退订后下次查询立即反映；没有跨请求缓存。

预检提示按当前情况说明下一步：无快照先完成原名单准备；原版无须续发；已有收据只查阅范围；未保存先保存并重新模拟确认；暂停或取消不提示提交；恢复后旧报告提示刷新；无候选说明不会补人。尚未载入收据只表示当前页面状态，点击续发仍由原服务核实是否已保存及实际资格。
