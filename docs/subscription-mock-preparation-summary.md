# 本地模拟余额与任务占位准备

管理员打开政策群发页面，可设置0–2000份虚构余额、填写原因并核对最新剩余量；不需要另授主题权限。获独立主题授权的主管只能为本人当前已确认、冻结的活动占位，没有余额读取和设置权限。所有动作仅限local和虚构任务，不发送邮件。

## 页面亲测

1. 管理员设置余额，记录有效1小时。核对显示设置份数、当前剩余、原因、到期和读取时间；过期或不可用显示明确提示。
2. 管理员给主管主题授权；主管保存政策草稿，生成中英文模拟邮件、分别确认可读，再冻结名单。
3. 点“准备一个任务占位”，成功后任务立即加入下方演练选择器，无需重新打开页面。每次只准备一个，不自动领取或运行。
4. 领取、开始和结果沿用原规则。追加新占位保留现有选择与内存凭证；最多5次/首次起23小时，待核对没有清除入口。
5. 回执不明时保留输入并锁住其他写入。余额设置仅“读取核对”，不自动重设；占位核实复用原动作和编号，不换键重复占位。已确认设置成功后的额外读取失败不重做设置。

仍受北京日2000份、同邮箱跨活动滚动24小时1份、当前余额、角色/主题授权/归属/来源/资格及暂停取消规则约束。占位与领取不算尝试，只有开始才计次数。界面汇总须点“刷新状态”，有自己的统计时间。
