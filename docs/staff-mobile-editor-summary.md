# 本地亲测：手机端录入与保存

手机端把内容、政策、报价、咨询和服务商表单按业务字段分组。编辑时，保存入口在屏幕底部。可用的保存按钮保留原来的校验和权限。内容与政策继续显示自动保存状态、禁用原因和失败提示。咨询和服务商沿用后台原有的保存。桌面保存位置沿用原布局。

## 合并后亲测

在本机同步 `main`，运行 `npm run demo:stop` 和 `npm run demo`，再用演示账号打开后台。手机可以按[本地测试指南](local-testing-guide.md)临时通过同一个 Wi-Fi 访问电脑上的演示站。使用虚构资料，避免影响日常数据。

1. **E5 指南。** 运营打开一篇虚构指南，从基本信息滑到正文和资料来源。编辑摘要或正文，确认键盘打开时仍能点「保存草稿」。刷新后核对内容，检查页面只有一个保存入口。
2. **E1–E4 政策。** 运营打开虚构政策，查看国家、适用条件、日期、来源与核实等分组。修改后保存，再进入任一种语言的公开说明，确认可以独立保存。送审后查看保存按钮旁的锁定提示。
3. **E7 咨询和报价。** 打开一条虚构咨询，核对跟进操作、客户联系与需求、内部跟进记录和提交来源。修改可编辑字段并保存，刷新核对。进服务单展开「新建报价版本」，先留空方案名称点底部保存，按提示补齐，再保存草稿。
4. **E9 服务商。** 打开一条虚构申请，展开联系与资料分组。滚到表单末尾，确认字段可见且底部操作可以点到。桌面上再打开同一条记录，确认仍可在原位置保存。

浏览器验证使用触屏视口和模拟键盘高度。实体手机可以重点核对输入长正文、切换键盘和滚到最后一个字段时的操作。
