# 活动暂停与恢复按钮：本地亲测

本批把原有暂停服务接到政策群发草稿页。获独立主题授权的主管只操作本人活动，管理员也须单独授权；原因必填。暂停后旧处理凭证失效，恢复仍须当前有效的双语模拟确认，不会发邮件。

## 怎么亲测

使用 Node24.22.1，保持本机演示 PostgreSQL 运行，在项目目录执行：

```sh
npm run test:subscriptions -- --preview --isolated-browser
```

这会启动 `http://localhost:3186/admin/login`，使用随机临时库；账号密码在终端提示的本机 `preview-accounts.json`，不要提交或分享。统一用 localhost 访问，避免影响原127.0.0.1演示站的登录。首次编译请等待页面加载完成，再点击按钮。

1. 用预览管理员登录，打开“政策群发草稿与主题授权”，给“预览主管1”授予政策更新操作权；退出后换主管1登录。
2. 打开同一入口，勾选虚构政策并保存。先空着原因点击“暂停本地活动”，应提示填写原因；填原因再暂停，应显示状态、时间和原因。刷新后仍暂停。
3. 未完成模拟确认时不能恢复。暂停期间可生成本地模拟邮件，查看中英文并逐一确认；填恢复原因后恢复。暂停时“冻结本轮名单”禁用，恢复后按原门槛开放。
4. 再勾选一条政策，先不保存，填写原因并暂停。刚勾选的资料应保留；要恢复须先保存并重新模拟确认。网络或服务失败时原因和当前选择保留，可重试。
5. 换普通运营，应看到无权使用的提示。另一位主管不能操作此人的活动。手机窄屏下原因框及按钮应可使用。

按 Ctrl+C 停止，脚本清理临时库和预览副本。原3100演示站、55442原库、图片和种子不动。请记录账号角色、操作步骤、时间和截图，不附密码、邮箱名单或处理凭证。

本机23组订阅集成通过，覆盖权限、同源、原因和版本校验、暂停后旧租约失效及恢复后仍拒绝；浏览器完成以上按钮主流程、失败保留、请求中禁用、低权限和窄屏检查。机器人操作不等同于你本人或新人已亲测；旧租约由接口集成验证，页面没有领取租约入口。

无新迁移、依赖或产品环境变量。原库若尚未应用此前迁移，仍须先配套备份、迁移并重启；本轮只自动迁移随机库。真实发送、worker调度、永久取消和重试等留后续，真实邮件、AI、语音、通话及正式评分保持关闭。截图只保存在本机忽略目录，未上传为PR附件。
