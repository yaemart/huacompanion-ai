# 内容中心与 AI 任务验收记录

日期：2026-10-27；仅本地测试，无外部部署。

## 已实现与验证

- 中文工作台 `/content-center`：管理员和内容编辑可访问，运营与匿名不可访问。
- 服务、指南、FAQ、固定页面、公开伙伴工作稿；中英文独立记录。
- 保存、预览、提交审核、管理员退回/发布/下架、恢复历史为新稿。
- 内容专用API承担全部写入，Payload原生集合只读；事务锁和版本号避免并发覆盖。
- 工作稿与公开快照分离，网页标题和正文使用同一公开内容；新增指南不受旧固定列表限制。
- 图片格式/像素/大小检查，重新编码去除元数据，未发布图片仅员工可读，下架且无其他公开引用后不可匿名读取。
- 48条既有中英文内容迁为草稿，不自动发布；测试期间另外保留了明确的虚构工作稿、测试AI任务和测试图片。
- AI任务支持人工保存、取消、未配置提示；执行器测试覆盖额度门禁、单并发领取、取消后迟到结果、候选校验、幂等采纳和语言身份。真实模型未接通。

验证结果：25项单元测试；内容和AI真实数据库集成检查；原业务13项集成检查；原表单8项HTTP检查；新增内容HTTP端到端检查；生产构建和类型检查通过。新增迁移在空库执行通过，含内容/版本/事件/任务的数据库恢复及2份真实图片文件校验通过。

浏览器操作已完整走通测试文章发布、草稿修改、旧正式版保持、重新发布、下架404。前台已验证标题同步。内容工作台桌面及390像素手机布局已查看，手机列表区域限制高度并支持独立滚动。

## 当前限制

- 模型供应商、模型、账户、额度、真实适配器与常驻worker尚未配置；自动测试使用的假适配器仅在测试代码注入，运营入口不能选择它。不存在可用的真实AI生成服务。
- 额度当前为保守令牌预留，未核实费用不释放预留；货币预算和真实供应商计费待接入验收。
- 来源为粘贴材料和引用网址，没有自动网页采集；没有定时任务或联网核实。
- 固定页面仅 home/about/contact/partners/privacy/terms，不能任意新增页面网址。
- 内容工作台和公开列表当前加载上限1000条，适合本地初期测试；大规模运营前增加分页。
- 原主页部分装饰布局改为通用内容模板；内容发布前，前台有空态，原草稿详情为404。没有隐藏的旧内容回退。
- 页脚品牌与导航等界面文案仍由代码维护；独立封面选取、定时过期提醒与人工译文关联复核仍待后续完善。AI翻译记录源稿版本，但人工维护的两条语言稿不自动推断翻译来源。
- 新版手机全流程专项、迁移回滚及生产压力测试尚未执行。旧的50页预览检查依赖所有静态详情存在，已由新增CMS发布/下架检查补充，不能宣称仍为50页全通过。
