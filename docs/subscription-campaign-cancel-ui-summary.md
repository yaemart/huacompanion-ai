# 后台取消按钮：本地亲测

获独立主题授权的主管，现在可以在本人活动中填写原因、勾选明确确认后取消未完成模拟任务。取消后不能恢复；历史、已完成记录和已占份额保留，不归还额度。只在本地模拟，不发真实邮件。

## 怎么亲测

使用 Node24.22.1，保持本机演示 PostgreSQL 运行，在项目目录执行：

```sh
npm run test:subscriptions -- --preview --isolated-browser
```

打开 `http://localhost:3186/admin/login`，用终端提示的本机 `preview-accounts.json` 中的虚构账号登录；不要分享密码。始终使用localhost，避免影响原127.0.0.1演示站的登录。首次编译请等待页面加载完成。

1. 管理员打开“政策群发草稿与主题授权”，给“预览主管1”授予政策更新操作权；退出，换主管1登录。
2. 在同一入口新建草稿，勾选虚构政策并保存。想看历史保留，可先生成模拟邮件、查看并确认中英文可读、冻结本轮名单；这不会发邮件。没有做模拟确认也可以取消。
3. 填写原因，展开“取消本地活动（不可恢复）”，阅读提示并勾选确认，再点“确认取消本地活动”。不勾选时按钮禁用；空原因会提示并聚焦原因框。已暂停或有未保存选择仍能取消，但取消不会保存这些修改。
4. 应显示“已取消”、北京时间和原原因，没有恢复、模拟确认或冻结入口。刷新后仍取消，原历史快照编号和人数保留。取消不可撤销；继续演练请新建另一份虚构活动。
5. 换普通运营，不能进入操作页面；另一位即使已获授权的主管，也不能打开此人的活动。若操作显示“待核实”，先点“核实活动状态”；核实未取消时重新勾选后再试，避免把网络失败当作没有生效。

按 Ctrl+C 停止，脚本自动清理临时库和预览副本。重启会得到新一套虚构数据，原3100/55442、图片和种子保留。问题请记录账号角色、时间、步骤和截图，不附密码、邮箱名单或领取凭证。

## 验证和边界

自动验证执行 `npm run test:subscriptions`，共25组，包含权限、同源、严格字段、显式确认、历史/份额保留和旧租约拒绝。份额及租约没有新增页面操作入口，由接口集成测试验证。

实际浏览器验证了未勾选/空原因、暂停未确认时取消、未保存选择、正常成功与刷新、4人历史快照保留、失败保留输入、服务端成功200后丢失响应再核实，以及跨主管/运营拒绝和窄屏布局。临时请求拦截已撤销、尺寸已复原；截图只在本机忽略归档，未上传PR附件。自动操作不等同于你或新人已亲测。

无新增迁移、依赖或产品环境变量；原库如果尚未应用此前迁移，仍须先配套备份、迁移并重启。真实邮件、AI、语音、通话及正式评分保持关闭，本批无需外部账号。预览验收先预热前台路由，未证明此前冷启动问题已解决。另有轻微文案待办：来源失效且活动已取消时，旧提示仍建议保存新版本；实际终态不能保存或恢复。
