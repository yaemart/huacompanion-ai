# 本地亲测 · 中英文订阅表单

首页、来华指南、免签工具和展会页的页脚上方显示「邮件订阅」。访客选择一个主题，阅读同语言的隐私说明，亲自勾选同意。打开确认邮件后还要点「确认订阅」才生效。

免签工具预选「政策更新」，展会列表预选「展会提醒」。仍有效的单场展会有单独选项，访客也可以换选其他主题。订阅和邮件配置、隐私版本、同语言已发布隐私说明缺少任一项时，整块表单隐藏。

## 用浏览器走一遍

1. 用 Node 24.22.1 启动原有本地演示 `npm run demo`，然后在另一个终端运行 `npm run test:subscriptions -- --preview`。预览只监听本机 3186，使用临时数据库。
2. 打开 [中文免签页](http://127.0.0.1:3186/zh/tools/china-visa-free-checker) 或 [英文虚构展会](http://127.0.0.1:3186/en/exhibitions/fictional-fair)。用不同的虚构邮箱，比如 `policy@example.invalid`、`fair@example.invalid`。先试不勾选同意，再勾选并提交。
3. 终端会显示「模拟确认链接」。在浏览器打开相应链接并点「确认订阅」，应看到确认成功。按 Ctrl+C 关闭预览，清理该次临时数据。原 3100 演示站与资料继续可用。

不带 `--preview` 运行 `npm run test:subscriptions`，可重复验证配置不齐隐藏、没有同意不入队、邮件确认和既有退订规则。日常演示保持原配置，表单默认隐藏。

这一批使用模拟邮件。工具结果页的「发到我的邮箱」和所选资料发送待单独接入。群发继续留在停止点 C。
