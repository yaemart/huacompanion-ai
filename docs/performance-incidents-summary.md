# 任务 G · 投诉、纠错与申诉亲测

这批实现登记、确认、站内通知和申诉复核。投诉从服务单进入，纠错从已发布的内容、政策共用事实或公开说明进入。人工判定依据[已确认口径](tasks/2026-11-15-performance-metrics-proposal.md)。

## 合并后在 3100 测

旧演示库先停站，配套备份数据库和图片，由开发者应用并登记 `20261115_130000_performance_incidents`。此前缺少的迁移依次补齐，再重启。新建演示库会应用迁移。已有资料可以保留。

1. **登记投诉**。运营用自己负责的虚构咨询创建服务单。在服务单点「登记服务投诉」，填咨询创建之后的发生时间、问题简称和凭据。到「我的登记」核对待确认。相同问题可补充原记录。
2. **判定并申诉**。换未参与该服务单的同团队主管，在「投诉、纠错与申诉」找到它。选「成立 → 华伴责任」，按事发记录选择该运营，填写给本人的说明，确认已移除客户信息后保存。运营到「站内通知」点「查看本人判定」，提交一次申诉，核对「待复核」。
3. **换人复核**。原主管打开记录，应看到须另找复核人。换未涉事管理员，填写理由并保存复核结果。运营收到自己的结果通知。可换新人确认看不到原运营的判定。
4. **登记纠错**。打开已发布的虚构指南、政策共用事实或中文／英文公开说明，从对应页面登记。共用事实选择错误涉及的字段，选中同一正式版本和字段后，用另一种语言描述再次登记，仍指向原登记。换未参与原发布的板块审核人或管理员判定。

投诉的个人选项来自事发时负责人的记录。内容按原发布版本记录的编辑、核实及审核职责选择。早期记录缺少可核实的责任历史时，个人判定保留待确认。相同投诉若用了不同问题简称，判定时可关联原编号并标为重复。申诉截止以北京时间为准，通知后的 7 个完整自然日内可提交。

后续批次交付个人看板、月报、评分和导出。按 SOP，试行前三个月先记录。
