# 本地全站邮件调度限速与订阅优先

用户要求PR104合并后，本地模拟营销接全站每秒1次、退让确认/资料，原权限/额度/共用预算/重试保持，无review清除。
基线392da87f8f35104145546818ae4518fdf826d87d。沿用已确认B默认，本轮不开放真实邮件或自动结果。

采用数据库私有单行闸门而非进程内定时器，全部本地队列入口（营销、确认/资料、通知、客户验证码）共用。
单次放行后至少1000ms（额外1ms覆盖毫秒存储取整）；SQL使用新鲜数据库时钟、全局事务锁。
营销等待不写attempt/审计，已开始/终态幂等判断优先。短时调度等待保留匹配的未开始凭证且不续期；
共用邮箱冷却仍按原规则丢弃凭证，过期凭证不能开始。候选只读提示等待，真正开始再次检查。
确认/资料、通知和验证码的两阶段任务先保留70秒在途占用，提交后再投递；投递前在同一闸门锁下验证占用归属，
持锁跨发送直到结束，再设至少1秒。崩溃仍有已提交在途占用；过期旧进程不能绕过归属恢复发送。

营销在有到期、当前同意/配置/来源/共用预算允许处理的确认/资料邮件时让行；失效、未到期及冷却中者不饿死营销。
复用原mail eligibility、正文指纹和政策当前投影，不另建宽松资格。仅返回等待原因和时间，不暴露收件人。
通知共用速率，不额外抢占确认/资料的业务优先级。生产/trial不启用本轮本地闸门，不因模拟开放真实外发。

统一锁序：原内容/业务/邮箱/任务锁在前、调度闸门在后；放行用try-lock避免跨链路等待。
投递guard可阻塞闸门但只包纯transport，不在其内获取业务/任务锁。开始事务中的闸门和attempt/审计一起提交/回滚。
不提前占用未来多个slot，下一可用时刻只是建议；限速/让行不新增尝试。失败/未知原次数和等待规则不放宽。

新增hidden/deny-all私有collection及迁移，类型生成，不新建产品环境变量/依赖；原库不自动升级，保留3100/55442和图片。
原回归夹具用显式调度时间推进，专门新组实际多进程/计时验证1秒、优先/非优先、在途/崩溃/审计回滚。
check、订阅与通知相关集成、空库迁移生产构建、隔离浏览器、一次独立复核、精确CI和中文交接；业务≤400行。

独立复核追加：通知未配置保持disabled；已预占但未进入transport的终止/失权/读取异常分支，
在原owner锁内释放占用并隔1秒；已进入transport却抛错保留70秒安全占用，不以收尾清除未知风险。
