# 本地模拟任务自动选择与领取设计

用户要求PR102合并后接本地模拟自动调度与领取，沿用权限、额度、重试，不开放清除待核对。
最新main为3ee9bd70f5bf9f02cd654f1a577accbb2d4ff96f，B方案及默认本地模拟规则已获既有确认。

## 范围与做法

主执行采用较小默认范围：页面主动开启自动领取，为本人当前活动自动选择并领取已占位任务。
开始和结果仍手动；不新增独立worker、自动占位或自动结果。已提出可选范围问题，尚无新答复，
依用户本轮授权及既有逐批流程推进此范围，不把该默认称为用户新确认。

比较：直接claim-next会使未知回执重试可能改领别项，需要额外持久操作记录；独立worker会持有
页面不能恢复的凭证且扩大到自动尝试/结果。采用只读选择+原逐任务领取，竞争由原事务锁和租约守卫。
选择结果只是候选，领取时重新校验，不承诺选择与领取原子完成。

服务只返回候选slotId、最早等待时间和服务器时间。跳过有效租约、尝试中、待核对/失败/完成、
取消、过期尝试、五次/23小时门槛及实时资格失效者；同等按占位编号升序，等待者到时再选。
稳定有效读取不写库；模拟确认上下文变化仍按原服务持久失效记录并拒绝，不绕过原规则。

页面默认关闭自动领取，开启后每5秒至多一轮，已有凭证或其他操作忙碌时停止选择。
领取成功保留原开始/结果按钮；记录结果后才可继续选择。没有任务则显示等待并继续轮询。
任何选择/领取错误停止自动模式；领取未知保留原任务请求，只允许核实，不再选择下一项。
关闭只停止后续轮询，不撤销已提交请求；刷新/离开页面停止，不宣称后台worker仍运行。

## 约束与验收

仅local，独立主题授权、当前角色/归属/确认/冻结/版本/来源/实时资格、暂停取消均复用。
不增加邮箱/哈希/正文/凭证读取权限；仅原领取成功返回凭证，页面内存保存。
不改余额/营销日2000/邮箱24小时1份、每任务5次/23小时/退避或待核对规则。
同源JSON16KB、私有响应头保持。Node24.22.1，无新依赖/迁移/产品环境变量，业务改动≤400行。
原3100/55442和图片保留，随机测试库清理，截图报告忽略归档，按项目要求check/集成/浏览器/CI。
权限与状态边界、竞争、等待、未知回执停止及原任务核实为验收重点；不以本地模拟开放真实发送。
