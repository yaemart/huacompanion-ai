## 使用方式

- 管理员在后台“报价模板”按现有八类服务维护内容。每个服务类型最多一份，停用后不再供选择。
  模板只含“包含项目”“不包含项目”“变更与取消规则”；字段非空，每项最多 4000 字符。
- 运营在自己权限内的服务单打开“新建报价版本”，从该咨询所选服务类型中选择并点击“填入模板”。
  仅填空白的三个字段，已有文字保留；填入后仍可修改。无可用模板时可继续手填。
- 保存报价时保存编辑后的文字。改动、停用模板不修改已有报价，包括已保存的草稿和历史版本。
  模板不填金额、成本、费用项、经营模式、主体或代收条款，不改变发送或审核权限。
- 人工和已有 AI 报价的有效期按北京时间输入和显示，客户看到的报价有效期也标明北京时间。
  保存仍用 UTC 时间点，明确带时区的 API 输入保留原含义，旧报价时间点不重写。
  不设置默认有效期天数，延用现有“未来一年内”校验；不调整非报价的服务预约时间。

## 实现选择

采用独立、仅管理员读写的 Payload 设置页，保存有界的类别模板。固定写在代码里会让每次改文案都要发版；
独立模板库支持多个版本、发布和共享，但本批每类只需一份，也无需重建报价流程。
选择服务单之后，服务端沿用已有业务及记录范围检查，只回传符合咨询类别的启用模板与三个文字字段。
未知类别、重复类别和非法字段在服务端拒绝；初始模板为空，不写入未获确认的服务承诺。
前端只在点击填入时复制，提交仍走既有报价校验、权限及保存流程。

新增设置需要增量迁移；原报价、客户数据和图片不回填、不重置。先在独立数据库验证迁移与回退保护，
并在交接记录明确本机所需步骤。无新依赖、环境变量、外部服务或对外发布。任务 F 的分项、主体和二审照原计划后续交付。

## 验收

- 管理员能维护模板；匿名、客户及无维护权限员工不能读取或改写原始设置。
  运营只能从授权服务单读取匹配类别的启用模板，跨团队和越权记录仍拒绝。
- 空字段填入、已有文字保留、多类别选择、无模板手填和停用后不可选；同一模板改动不影响已存报价。
- 在不同时区输入同一北京时间，得到相同 UTC 到期时间；覆盖跨日、非法日期、历史带偏移量值和过期边界。
  回归现有金额／成本可见性、发送／确认及 AI 草稿；不启用真实 AI 或邮件。
- `npm run check`、相关业务／权限／客户集成和本地后台验收；lint 警告不增加，实际结果记入 `docs/progress.md`。
  提交一份独立草稿 PR，截图附 PR；合并由用户决定。
