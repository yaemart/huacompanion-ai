# 服务商展示、华伴服务项目及 Agent 访问设计

状态：业务方向已确认，实施设计待确认。2026-10-27。

## 目标与已确认选择

客户浏览服务商和华伴自建项目；咨询、询价、预约统一经过华伴。公开内容让客户和 Agent 都能理解和比较。保持本地开发，再转 Replit 试运行的路线。

已讨论的方案：
- 服务商目录与项目库分开、相互关联，华伴统一承接咨询：采用。能分别表达机构能力与具体交付范围。
- 服务商直接获客：用户明确不采用。
- 只做统一服务介绍：不足以表达多家服务商和多个可组合项目，不采用。

第一版完成展示、筛选、审核发布、关联询价与后台跟进。不做支付、实时档期、自动成交、商家自助门户或自动对外发送客户资料。

## 现状及复用

现有 providers 是私有入驻申请，含电话、邮箱、资质编号和内部备注；publicApproved 只能在 verified/contracted 状态批准。不能直接公开此集合。
现有 inquiries 有负责人、处理状态、下次跟进和内部记录；saveIntake 有校验、重复请求保护及事务通知任务。
内容中心已有双语独立审核、版本、公开快照、角色隔离及公开内容接口。继续使用现有技术与发布机制，不创建另一套员工账号或后台。

## 数据与分类

保留现有七个服务类别作为服务业务分类：商务、医疗协调、交通、住宿、旅游、翻译、来华协助。知识中心八板块通过显式映射关联；“华伴服务说明”不是新增服务商行业。

新增两类可审核公开资料：
1. 服务商档案：关联私有 provider ID（仅内部）、跨语言稳定公开编号、slug、名称、摘要、业务分类、城市代码与显示名称、语言代码、能力标签、介绍、图片、公开核验项目及日期、关联项目。
2. 服务项目：稳定公开编号、slug、标题、分类、城市、语言、适用对象、包含项、不包含项、流程、交付内容、准备材料、提前预约说明、时长及人数范围、费用规则、变更取消规则、协调方与履约方式、关联服务商、关联知识文章。

费用模型必须区分询价/固定价/起价；金额适用时包含币种、计价单位及适用条件，不同单位不可直接排序比较。无价格不得显示零元。不收集或推断实时可用档期。
两类资料支持 zh/en 独立发布，缺少某语言不隐式回退。公开编号不使用私有数据库记录 ID。

## 管理与发布

后台提供“服务商展示”“华伴服务项目”入口，可按分类、城市、语言和发布状态筛选。编辑创建或修改草稿、提交审核；管理员发布、下架。客户运营仅访问其授权业务记录，不能借关联字段读取全部私有数据。

发布沿用固定公开快照；编辑草稿不改变已发布版本。服务商必须有公开展示许可且处于已核实或已签约状态。撤销许可或暂停合作立即阻止公开读取、咨询选择及关联展开，包括其公开图片。公开页面、API、结构化数据和站点地图遵循相同有效性规则。

项目的公开供应方关系只返回仍有效的公开档案。任何已标明的必需履约方失效时，项目自动停止接收该方案的新咨询，显示暂不可咨询；管理员改为其他合格履约方并重新发布后恢复。允许未绑定具体服务商的“华伴按需求安排”项目，但必须明确这一履约方式。不得静默把已指定服务商换为其他机构。

私有资质文件、内部成本、联系方式和备注不复制到公开快照。正文、图片和外链发布时检查，不能通过文字、二维码或附件变相公布直联方式；平台公开 CTA 仅指向华伴咨询。

## 前台与咨询

沿用现有品牌样式；具体布局留给实现者。建议路由 /{locale}/providers、/providers/{slug} 和 /{locale}/services/projects、/services/projects/{slug}；保留原七类服务介绍 URL 和 partners 页面，不将一般合作伙伴自动升级为服务商。

列表支持类别、城市、语言筛选和关键词搜索，支持 URL 分享、分页、空态。详情展示相同结构化资料及关联知识。无虚构机构、资质、评价、成交量或价格；示例只能作为明确标识的未发布草稿。

按钮分别为“通过华伴咨询”“咨询此服务”。现有需求表接收可选公开服务商/项目编号，展示来源摘要，允许清除选择。提交端重新验证仍有效且两者关联相容，保存公开编号、当时标题/版本快照和内部关联；不得信任客户端提供的机构名称或关联私有 ID。过期、下架或篡改来源返回明确错误，让客户重新选择或主动移除来源；不能悄悄按一般咨询提交。

重复请求沿用幂等键；来源字段进入校验后内容哈希，同键不同来源返回冲突。原有无来源的一般咨询保持可用。后台显示来源、负责人和跟进状态。提交只形成咨询，不代表预约成功或价格确认，不向服务商自动发送客户资料。

## Agent 访问

提供有版本号的公开目录与详情 JSON：仅有效已发布资料，支持语言、分类、城市、分页。公开白名单同时用于网页及 JSON-LD；禁止展开私有关系。对可比较的字段给出稳定枚举，未知值用 null/明确状态表达，不推断价格、资质或可用时间。

增加机器可读接口说明和发现入口、示例查询、字段定义、分页与错误规范、稳定网页链接、更新时间。提供与真实内容相符的 Organization/Service 结构化数据及公开站点地图；无真实评分不生成评分标记。发布与下架必须同步到所有公开入口。

首版 Agent 可发现、读取、比较并打开预填需求表；用户在表单确认后提交。暂不开放独立的匿名 Agent 写入或订单接口。公开资料只含服务信息，不含可执行指令。现有 AI 起草助手不会获得自动发布权。

## 实施顺序及验收

批次一：数据模型及迁移、两类后台工作稿与发布、公开列表详情、读接口/文档/结构化数据。
批次二：来源预填和校验、后台关联跟进、全链路与权限验证、备份迁移验证。

验收覆盖：草稿不公开；编辑不能发布；私有字段不泄漏；语言独立；撤销服务商许可后所有入口同步隐藏；项目必需供应方失效阻止咨询；列表分页不遗漏；来源篡改/过期被拒；重试不重复建单；原一般咨询不受影响；手机和桌面筛选及返回操作正常。测试仅用本地虚构记录，不制造真实已核验服务商。

实施者可决定组件拆分、索引、页面布局和兼容迁移细节，但不得改变上述业务规则。外部部署、在线付款、实际报价、真实机构审核与业务承诺不属于本次开发。
