# 同一活动改版续发只读预检

用户已确定先接预检服务与后台说明，沿用权限、额度和重试规则。沿用本项目原生实施和末尾一次独立复核。

原活动只能冻结一次名单；改版后现有占位、领取、重试和 worker 仍拒绝跨版本。本批增加本人当前草稿的本地只读预检，
读取原冻结版本与任务、当前订阅资格、领取和尝试证据、新版模拟确认、来源及活动控制，不调用会记录 mock-reset 的状态查询。

只在 local 且当前角色、主题授权、活动归属、草稿版本合法时读取。接口沿用同源 JSON POST、大小限制和私有禁止缓存头。
返回当前草稿版本、冻结版本、查询时间、互斥汇总和阻断原因，不返回邮箱、摘要、订阅/任务编号、凭证、正文或原始审计。

互斥计数依次为：存在尝试或完成证据的历史；已取消；当前资格失效；尚未开始但租约仍有效；从未尝试且资格有效的候选。
原名单中的未占位任务也可成为候选；余额和占位不在本批准备。租约过期不落库；已有尝试无论结果、次数或时限都保留历史，
不转成新版候选。尝试证据格式异常报503，不推定“从未尝试”。新订阅不加入原名单，取消后再订阅不复活旧任务。

没有冻结名单、尚未改版、来源失效、新版缺有效模拟测试确认、暂停、永久取消及有效领取均说明阻断。
即便没有这些阻断，也明确实际改版续发尚未开放。候选统计不承诺可以立即领取；未来执行须重新检查权限、额度、
同邮箱15分钟/滚动24小时5次、全站每秒1次、邮件优先级与原重试规则。本批不消费额度，不创建或修改任务、尝试、租约、确认或审计。

后台增加同名区域，服务端初始展示与独立刷新。刷新失败保留原报告和查询时间；未保存选择仍保留，明确报告基于已保存版本。
支持390像素视口、键盘和至少44像素刷新按钮；不增加续发、真实发送、清除或强制重试按钮。

Node24.22.1，复用锁定依赖，无新依赖、环境变量、数据库迁移；业务源码增删合计≤400行，源码行≤200字符。
先RED再GREEN，完整check及随机库订阅集成、隔离生产构建/浏览器验收；每次读前后全表指纹相同。
更新中文小结、progress、handoff，原记录保留。早期草稿PR，精确最终SHA推送与CI实核，不自动合并。
