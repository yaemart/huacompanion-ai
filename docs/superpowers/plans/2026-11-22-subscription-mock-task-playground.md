# 本地模拟任务领取、尝试与结果演练计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans。主执行自行TDD实施，完成后一次新上下文只读复核，不分派实现。

**Goal:** 获授权主管可在本人活动页选择已占位任务，领取凭证、开始一次本地尝试并记录模拟结果。

**Architecture:** 只读任务选项仅返回当前冻结批次的占位编号；POST分别直接复用claimMockCampaignTask、beginMockCampaignAttempt、recordMockCampaignOutcome。客户端凭证仅当前页面内存保存；请求结果不明时冻结相同输入并核实原操作，不切换任务/结果，其他表单互斥。

**Tech Stack:** Node24.22.1、现有Next/React/Payload/PostgreSQL；无新依赖。

**Spec:** 用户要求PR100合并后接领取/尝试/结果，沿用既有重试规则且不开放清除待核对；用户明确选择只处理已占位任务，余额和占位继续由现有服务准备。基线e4765bdcc86035331e41cf77346ea86d73ed5976，沿用已批准B方案6.1/6.2和PR97服务。

## 设计与范围

- 采用逐任务三个明确步骤，返回原服务回执，不合并成自动循环。选择器仅列本人的当前批次占位编号，无订阅邮箱或逐人资料。
- 比较过自动取下一任务及自动开始，两者会扩大调度和未知结果边界。本轮显式选择已占位任务，不新增预算/占位页面或接口。
- 领取不计尝试；显式开始才计一次；五种结果为模拟完成、临时失败、429限速、结果不明、永久失败。429可填写等待秒数，真实邮件/外部调用保持关闭。
- 同任务最多5次/首次23小时；30秒指数退避与更长Retry-After，未知或开始后租约过期停待核对，无重置/清除入口。旧完成接口不开放。
- 成功回执原地展示；PR100汇总保留统计时间，操作后点击其刷新按钮更新，不因额外读取失败将已成功操作误称未知。
- 页面刷新会丢弃本页凭证。未开始者到租约期后可重新领取；已开始者失效按原规则进入待核对，不从读取接口恢复凭证。

## Global Constraints

- 仅local，当前角色/主题授权/本人当前版本/有效模拟确认、来源、暂停/取消、实时资格及@example.invalid门禁保持；非本地/跨主管/旧版拒绝。
- 使用原同源、JSON、16KB和private no-store响应。输入严格由既有服务校验；凭证仅领取成功回执返回，不进入SSR、读取选项、URL、存储、审计或界面文字。
- 等待/待核对/失败/完成不能用开始、旧凭证、改结果或换租约绕过；重复操作不增加尝试/审计或额度。
- 请求期间和结果不明期间锁任务、结果及其他活动表单。未知结果只能核实相同动作和输入；明确4xx拒绝可解除锁定，网络/5xx/无效成功响应不得声称完成。
- 源码行≤200、lint警告≤445、单批业务≤400行；无新增迁移、依赖或产品环境变量；原3100/55442和图片保留。
