# 本地模拟任务状态接入计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans。主执行自行TDD实施，完成后一次独立只读复核，不分派实现。

**Goal:** 获授权主管在本人活动页查看本地任务汇总，并通过同源接口刷新重试和待核对状态。

**Architecture:** 复用withCampaignDraft的当前员工、主题授权、归属和版本门禁，读取原冻结批次下的私有状态，仅返回数量和时间。页面首屏及read-mock-status-local接口共用服务。读取不改状态、不领取任务、不尝试传输。

**Tech Stack:** Node24.22.1、现有Next/React/Payload和PostgreSQL；无新增依赖。

**Spec:** 用户要求PR99合并后接入本地模拟任务的重试与待核对状态；沿用已批准B方案6.1/6.2及PR97五次/23小时/未知结果停止规则。main基线804af1895a34723af923a69b64e73308612f733d。

## 范围与实施选择

- 采用状态汇总和刷新入口。现有服务操作维持原语义，人工清除待核对、调度和真实发送继续后续。
- 比较过逐人任务列表和操作演练面板。前者增加不必要的明细边界，后者涉及尚未接入页面的余额/占位/领取流程，本批按请求中的“状态”聚焦汇总。
- 读取原冻结批次，即使已保存新版也不混入新版本；展示快照版号及当前版关系。无快照显示空状态。
- 统计互斥分类：未占位、待领取、已领取、尝试中、等待重试、重试时间已到、待核对、永久失败、模拟完成、资格已取消。
- 尚未持久转为review的租约过期、首次23小时耗尽、retry达到五次等记录，读取按待核对显示，不写库。到重试时间只表示时间条件，不承诺当前资格有效或自动运行。

## Global Constraints

- 仅APP_ENV=local；匿名、无授权、停用/不再主管、跨主管拒绝；严格两字段输入、旧版409、同源/JSON/大小及私有no-store响应。
- 来源/配置失效、暂停/取消不遮蔽已存历史；读取不开放处理。页面清楚说明不自动重发、待核对不能在此重置、本地完成不代表投递。
- 不返回邮箱、订阅ID、正文、哈希、任务键、租约凭证或逐人记录。只返回版号、数量、统计时间、最早重试时间。
- 不修改原业务状态/审计/份额/余额/队列，不新增迁移或产品环境变量；原3100/55442和图片保留。
- 源码行≤200，lint不增加，单批业务≤400行。截图/原始日志仅本机忽略归档，未上传时明确说明。

## Review Focus

1. 按当前账号重新查角色与授权，不信任客户端或旧会话角色；跨主管与旧版不能读取。
2. 终态和资格取消优先，重试到时与五次/23小时边界、过期尝试分类互斥，总数守恒。
3. 读取与刷新无写入；超时推导和原持久状态的差异有清楚文案，无隐式“恢复”。
4. 改版后仍展示原批次，来源/配置/暂停/取消历史保持可见，不把历史计数称实际送达。
5. 刷新失败保留旧统计并标明未更新；页面刷新不丢未保存选择，手机可读。
