# 华伴多模态客服实施计划与验收状态

用户已批准六批规划并要求连续实施。沿用本地分支，原有文件不覆盖；各功能可独立启用，默认只有文字开放。

## 应用端已实现

- [x] 1. 配置后台、服务端开关及在途任务保护；会话／未发送草稿恢复、幂等重试，普通日期／人数／预算不再一律转人工。
- [x] 2. 私有 WAV 语音存储、录音试听上传、双方授权播放；格式、大小、时长、权限和重试保护。
- [x] 3. 持久化转写／朗读任务及已有内部翻译；显式同意、客户核对、敏感内容转人工、额度预留和超时处理。
- [x] 4. 浏览器 WebRTC、字幕、静音／结束、限次重连、时长和金额预留，可信发布知识与 AI 通话网关契约；终止后保存未核实内部摘要。
- [x] 5. 员工在线状态、语言与容量、接听队列、抢接防冲突、拒接／转接／过期释放；网关证明员工真正连接后切换人工。
- [x] 6. 权限内用量、首次回复／解决时长、满意度和知识缺口；独立文字／音频／转录保留策略，默认关闭删除、管理员预览确认与审计；部署文档和迁移。

## 本地验收

- [x] 90 项单元测试、类型检查、完整网站构建、含新增客服表的空库迁移。
- [x] 原客服与 AI 集成回归；私有语音、真实数据库通话流程（测试网关）集成。
- [x] 运营权限与保留策略测试；真实数据库事务内验证文字清理不推迟音频／转录策略，最终完整回滚。
- [x] 独立代码审查并修复 4 项发现：录音防重入、卸载后迟到麦克风、终态轮询清理、保留期限相互影响。
- [x] 浏览器验证会话和草稿刷新恢复、虚构消息保存；七语言 HTTP 页面与权限检查；未配置通话不展示入口且接口拒绝调用。

## 外部服务阻塞（不能算真实服务验收完成）

- [ ] 配置并部署真实模型与转写／合成适配服务，匹配文档接口；当前只完成适配器和受控测试，未接通真实模型。
- [ ] 配置并部署实现文档协议的 WebRTC 媒体网关（含 AI 音频、真人音频桥接和网络中继）；应用端接口不是媒体服务器本身。
- [ ] 两台实际设备验证七语言语音、字幕、AI 打断、人工接管、受限网络／断线重连，以及供应商实际停止计费。

没有供应商服务、凭证和可达媒体网关，不能宣称第四／第五批真实通话已经完成上线验收。代码功能与真实服务开放严格区分。开发不会因阶段完成而停止；当前剩余项需要外部服务条件。
