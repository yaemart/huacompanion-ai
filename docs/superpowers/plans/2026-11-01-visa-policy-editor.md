# 入境政策后台表单 1.1c2 Implementation Plan

Goal: 在现有/content-center?kind=immigration-policy入口完成字段编辑、核实人选择、审核确认与历史恢复，复用1.1c1事务服务。公开工具仍关闭，仅本机临时开启验收。
Spec: docs/traffic-entry-task.md; docs/traffic-entry-phase1-plan.md; docs/immigration-policies.md。
Architecture: 政策用独立表单组件与原工作台样式，旧ContentCenter不扩展any。受保护GET一次事务返回同一版本的工作稿/政策及最少核实人信息，沿用内容→员工锁和实时授权。新页面分支、后台导航和读接口仅VISA_CHECKER_ENABLED=true出现；通用集合权限不放宽。写入仍调用现有content-center API，已审核快照不进入公网列表。
Global Constraints: 业务源码目标400行内，超出先进一步拆分；无新增any/依赖/服务/费用，不改实际.env，不部署/合并；本轮拆分两个小PR：1.1c2a读适配依赖PR7，1.1c2b界面依赖1.1c2a，均在本轮完成；源码行<=200。
Design rulings: 不把政策塞入旧1410行大组件，保留同一入口/权限/样式，用独立表单维护。核实人列表仅ID/姓名，不返回邮箱、账号角色或凭据。结构化政策字段完整即可审核，不强制另造文章段落；只豁免新政策类型，旧内容正文规则不变。新表单不提供AI操作。未保存时不能提交/审核，修改/选择/恢复后重置人工确认。界面以工作稿/已审核快照描述状态，不称工具已公开。
