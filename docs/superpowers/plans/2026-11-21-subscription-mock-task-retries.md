# 本地模拟任务重试与待核对实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 自行TDD实施，一次新上下文只读复核，不分派实现。

**Goal:** 本地模拟尝试保留同一正文和任务键，临时失败有限重试，未知结果停为待核对，旧租约或旧完成接口不能绕过。

**Architecture:** 私有逐份额尝试状态表保存冻结正文/键、最多5个数据库时间、绑定领取凭证的摘要及下一次时间。原租约事务内接入begin/result和claim/complete门禁，复用当前权限/确认/资格锁；无API、页面、worker或真实传输。

**Tech Stack:** Node24.22.1、Payload生成类型、PostgreSQL15；无新依赖。

**Spec:** 已批准群发B `docs/tasks/2026-11-19-subscription-broadcast-options.md` 6.2；用户要求PR96后先做本地重试/待核对。基线 `4baf78b6f73f9fa01251e24f55be17a035c8669f`。

## Global Constraints

- 现有独立主题授权、本人/当前版本、有效模拟确认、暂停/取消、同意/语言与@example.invalid门禁不变；与退订和发布共用原事务锁。
- 领取不算尝试；显式begin才冻结正文/键并记数据库时间。换租约、重复begin/result不重置次数或重占营销份额。
- 同任务最多5次，首次尝试后最多23小时，边界含到期即停止；30秒指数退避沿用单封逻辑，429取更长Retry-After。等待超过窗口直接待核对。
- 结果unknown、进行中尝试租约失效或次数/窗口耗尽→review；不自动换键/重发、不提供人工清除review。permanent仅本地该任务停止，不声称全局退信/投诉处理。
- accepted仅标为本地模拟完成，非真实接受/送达；旧未进入尝试的租约演练保留原完成语义。已进入尝试后旧complete不能绕过等待/review/failed。
- 私有状态表和审计同事务，失败全回滚；审计/返回不含邮箱、正文或凭证/摘要。原份额/预算/历史保留。
- 本批只逐任务服务。跨确认/资料共用尝试预算、全站调度、回执/拒发、UI留后续，真实发送保持关闭。
- 新迁移仅随机库，有尝试数据拒绝回退；原3100/55442/图片/种子不改。无新环境变量/依赖。源码行≤200、lint≤445、单批业务≤400行。

## Review Focus

1. 活跃租约与一次尝试区别清楚；进程中断后未知尝试不能按普通过期领取恢复重发。
2. 同任务5次/首次23小时/退避不可因换租约或旧完成接口绕过，重复与迟到结果不改新尝试。
3. 首次正文和唯一键冻结且审计不泄露；改版/退订/撤权/暂停/取消的现有门槛仍生效。
4. 审计COMMIT失败时尝试状态、完成/失效租约全部回滚；多进程竞争只记一次。
5. 迁移保留旧租约演练；旧未开始尝试可正常恢复，进入尝试后终态不可恢复或假装送达。
