# 本地亲测 · 订阅完整流程

本轮把中英文订阅申请、模拟确认邮件、后台统计和 CSV、退订串起来验证。只使用虚构邮箱和临时库，真实邮件及群发保持关闭；群发方式仍等停止点 C 确认。

## 启动与关闭

用 Node 24.22.1 运行 `npm run demo`，另开终端运行 `npm run test:subscriptions -- --preview`。访问 [中文首页](http://127.0.0.1:3186/zh) 或 [英文首页](http://127.0.0.1:3186/en)。账号文件位置、模拟确认链接和模拟退订链接会显示在终端；账号文件只保存在本机。请勿把带凭证的链接贴到问题表或截图中。

**不需要运行 `local:reset`。** 按 Ctrl+C 关闭预览就会删除本次临时库和账号文件；再次运行即恢复初始的 28 条样例。原 3100 演示资料保留。每次复测使用新的 `@example.invalid` 邮箱，避免触发同邮箱冷却。

## 本轮可测的订阅专项

| 编号 | 操作                                                                                               | 应看到什么                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| S1   | 中文首页填 `try-zh@example.invalid`，选采购指南；先不勾同意提交，再勾选提交                        | 未勾选被阻止，输入保留；提交后提示尚需邮件确认                             |
| S2   | 用临时管理员登录 3186 后台进入订阅管理；打开终端的模拟确认链接，先只看页面，再点确认               | 只打开仍为待确认；点击后变已订阅；再次使用确认链接被拒绝                   |
| S3   | 主题选采购指南、状态选已订阅，点查看再导出；到操作记录核对                                         | 有自己的邮箱；CSV 带中文状态和截至时间；审计有导出人、条件和条数           |
| S4   | 打开该邮箱的模拟退订链接，先只看，再点退订；刷新管理页和导出                                       | 只打开不退订；点击后进入已退订；已订阅导出不再含该邮箱，已退订导出保留记录 |
| S5   | 手机尺寸在英文首页用新邮箱选择 Exhibition alerts，重复申请、确认、退订；退出管理员改用临时运营账号 | 英文回执完整；运营无法读取或导出名单                                       |

Excel 如出现导入向导，选 Unicode (UTF-8) 和逗号分隔。日期可能被 Excel 自动改成斜杠格式，窄列可能显示 `#####`；可拉宽列，需保留原日期字符串时按文本导入。CSV 原文件按北京时间输出。

## 本轮实际结果与未验项

浏览器完成中英文提交和确认、管理员筛选导出，以及 S5 的 390 像素英文退订模拟；API 验证同一条记录三个状态下的名单、导出和审计，匿名与运营被拒。Excel 原生导入识别 UTF-8，8 列、1 条数据和中文显示已核对。`npm run test:subscriptions` 十组通过，包含邮箱客户端一键退订的模拟协议测试。

真人手机的操作用时、外国朋友无指导体验、真实邮件送达及真实邮箱客户端的退订按钮仍未验。原测试清单 C6/C7 的订阅相关输入与双语界面可结合本页复测，其余场景及上线门槛不据此判定通过。所选政策资料邮件另见[亲测步骤](visa-policy-email-summary.md)。记录问题时写 S 编号、语言、操作步骤、预期、实际并附遮住邮箱和凭证的截图。
