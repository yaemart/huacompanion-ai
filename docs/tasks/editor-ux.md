**P1（与P0一并纳入任务E）**

3. 服务商资料：

- "支持语言""服务区域"改为标准多选；
- 主管可以在本人数据权限范围内审核服务商申请（核实通过 / 签约 / 暂停）；每次操作必须填写原因并写审计；不得因此获得管理员权限或自动公开展示。补充主管允许、普通运营拒绝、越权拒绝、缺原因拒绝及审计集成测试。
