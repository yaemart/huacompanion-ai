# 任务 G · 月度评分卡方案

2026-11-15 · 已确认。依据 PR65 合并后的 `main`（`ead2894`）和已确认的投诉、纠错及申诉口径。

## 后台配置

在「个人业绩与月报 → 评分规则」由管理员维护。每套规则配置适用职责、按月适用的员工、各指标权重、达标值、零分界线和最低有效样本。参与计分的权重合计 100%，权重为 0 的指标只展示数据。兼岗员工按月选用一套合并模板，发布前可预览字段、权重和算例。员工看本人，主管也看本人，管理员可看所有员工的评分卡。

规则先存草稿，再安排到未来某个北京时间自然月生效。月初锁定规则版本及员工适用模板。改权重、目标值、最低样本或名单时记录操作者、时间、变更前后内容和原因，安排在后续月份生效。旧月份使用当月规则。员工看到实际值、目标、有效样本数、计分状态和适用规则版本。

## 建议起始配置

以下数值用于评审和试行观察，试行后可根据实际样本校准。按岗位配置的权重如下。

| 指标               | 运营 | 内容编辑 | 审核人 | 建议达标值 → 零分界线    | 最少有效样本                                              |
| ------------------ | ---: | -------: | -----: | ------------------------ | --------------------------------------------------------- |
| 首次响应时长中位数 |  25% |       0% |     0% | ≤ 1,440 → 2,880 分钟     | 5 条可确认首响的咨询                                      |
| 按时跟进率         |  45% |       0% |     0% | ≥ 90% → 60%              | 5 项到期且可核对的跟进                                    |
| 个人有效投诉数     |  30% |       0% |     0% | 0 → 3 件                 | 零件时，至少 5 条该员工有可核对处理记录的咨询             |
| 内容按计划发布数   |   0% |       0% |     0% | 待有计划发布日期后再配置 | 当前显示缺少计划数据                                      |
| 审核退回率         |   0% |       0% |     0% | 观察退回情况             | 展示退回件数和审核总数                                    |
| 个人发布后纠错次数 |   0% |      60% |    40% | 0 → 3 件                 | 零件时，至少 5 次本人有明确编辑或审核职责的正式发布       |
| 逾期复核待办数     |   0% |      40% |    30% | 0 → 3 项                 | 零项时，至少 3 项截至当月应复核且有明确负责人和期限的待办 |
| 审核处理时长中位数 |   0% |       0% |    30% | ≤ 1,440 → 2,880 分钟     | 5 次能配对送审与结论的审核                                |

首响和审核时长沿用现有月报的实际经过时间（含非工作时间）。首响目标是内部指标，官网回执仍按工作日口径。审核退回率用于发现稿件反复退回或审核流程卡点，保留正常退回的空间。负向计数为零时，需要有足够工作记录支持。已有最终确认的个人投诉、个人纠错或有效逾期待办，本身就是对应的有效证据，可以计算该项。

## 正式计分与缺样本

达到目标拿足该项权重，到达或越过零分界线得 0 分，中间按距离线性换算。后台校验目标方向和单位，按数值越高越好计分的指标须满足「达标值 > 零分界线」，数值越低越好的指标相反。内部保留计算精度，展示总分时四舍五入到 1 位小数。

缺来源、未分配任务、样本不足的项目分别显示原因，排除出本次计分。没有待定项目时，至少 **2 项可计分，且覆盖原配置权重的 70%**，才按可计分权重归一成 100 分制。未达条件显示「样本不足，暂不出总分」。同时展示覆盖率和逐项权重。例如运营首响样本不足，另两项权重合计 75%，若分别得 90 和 80，月度总分为 **86.0**，覆盖率为 **75%**。

## 待定、跨月与重复计数

- 待确认登记只作为月报的待定事项。未确定归属时，登记人及其他员工的个人评分照常按本人的有效记录计算。
- 已明确归到本人的事件，在申诉期或独立复核期间将对应质量项标为「待定」，该项分数和月度总分暂缓出具。本人已结案、其他员工仍在申诉时，个人评分采用本人状态。待定记录保留可核查的状态和编号，原始证据沿用现有权限。
- 申诉期届满无申诉或复核完成后，按首次确认所在月计入原月。维持、变更责任人或撤销后，按原月锁定的规则重新计算，保留更正时间和原因。
- 同一员工的同一问题若有明确关联的投诉和纠错，月报继续分开列。兼岗评分用一个「已确认质量事件数」计分项，同一件只计一次，归最早符合计数条件的首次确认月。同事各自责任按本人判定处理。已标为重复或已撤销的记录排除。

## 三个月试行

由管理员配置试行开始月，从指定的首个完整北京时间自然月连续计算三个月。试行月只记录指标、样本、待定及复核结论，**不生成分数，也不扣分**。试行结束后保留三个月的观察记录。正式评分需要另行批准并指定生效月份，第四个月到达时仍按记录模式，直到批准生效。试行月永久保留观察记录，不追补分数。
