# 华伴本地测试清单

上线前必须在本地通过这份清单。每个开发 PR 合并后测一轮，问题记在《华伴本地测试清单》在线文档的问题表里。

## 通过标准

- 上线门槛：下面两类场景全部通过，并且没有未解决的"严重"问题。
- 编辑友好：一位没用过系统的人，不看说明、不问人，独立完成每个编辑场景，每项不超过 10 分钟。
- 客户友好：一位外国朋友用手机，在 3 分钟内完成每个客户场景，不需要问人。

问题级别：

- 严重：做不下去、显示错误信息、数据丢失、看到不该看的信息。上线前必须解决。
- 一般：能做完，但会犹豫、点错、要问人。尽量在上线前解决。
- 建议：样式、措辞、顺手程度。上线前不强制。
