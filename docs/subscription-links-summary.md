# 本地亲测：订阅确认与退订链接（H 2.2b 第一批）

访客打开模拟邮件中的链接，可以在中英文页面确认订阅或退订当前主题。打开链接只显示按钮。点击按钮后才提交操作，邮箱客户端或安全扫描器预取页面时订阅状态保持原样。确认和退订都可在无登录会话中完成。

确认链接有效 24 小时，退订链接有效 365 天。确认和退订各使用一次。退订也可取消待确认订阅。用户重新同意后会产生新版本，旧链接随即失效。凭证位于链接片段，浏览器读取后清除片段，点击时通过同站请求正文提交。

## 在 Mac 上亲测

同步代码，使用仓库指定的 Node 24.22.1。按[本地测试指南](local-testing-guide.md)启动演示环境，保持本机演示数据库运行。另开终端，在项目目录执行

```sh
npm run test:subscriptions
```

命令用虚构邮箱创建独立临时库，测试完成后清理。看到三条 `PASS` 即通过。第三条覆盖默认关闭、打开链接只读、免登录确认、取消待确认订阅、并发退订、再订阅及旧链接失效。测试进程临时开启页面开关，现有演示操作和数据沿用。

本批增加 `SUBSCRIPTIONS_ENABLED`，默认关闭。后台表结构沿用 2.2a。页面需要浏览器 JavaScript 读取链接片段。本机已用 Chrome 手机及桌面视口核对模拟邮件链接，并验证试运行门禁内操作。截图保存在本机。
