# 本地亲测：日期和版本名称

内容和政策编辑区用「草稿」「已发布版本」「第 N 版」区分可编辑记录、公开版本和历史，待审核或待复核状态仍单独展示。后台列表、工作台日期和历史以北京时间显示，日期写为 `YYYY-MM-DD`。报价有效期、跟进和申诉截止保留时刻，审计保留秒。日历日期如政策生效日按原日期显示。

Payload 自带的版本比较、记录元数据弹窗及日期输入控件仍使用浏览器时区或控件的输入格式。已保留这些控件原有录入行为。已有通知和审计原文仍保留。

## 合并后亲测

同步 `main`，先运行 `npm run demo:stop`，再运行 `npm run demo`。使用现有的 [3100 演示站](http://127.0.0.1:3100/admin) 和虚构资料。

1. **E5 指南。** 打开一篇已发布的虚构指南。分别看「草稿」和「已发布版本」各自的「第 N 版」。打开「历史版本」，核对版本号及 `YYYY-MM-DD`，再打开草稿预览。
2. **E1–E4 政策。** 查看共用事实和本语说明。已发布版本和当前草稿应分开，待复核的已发布说明会明确说明公开页暂不展示。
3. **E7–E8 咨询与报价。** 在咨询列表查看创建日期、下次跟进时间。进入虚构报价，查看版本号和报价有效期。用跨午夜的示例核对时区，`2026-12-01 16:15 UTC` 应显示为 `2026-12-02 00:15`。切到其他浏览器时区后再核对同一条记录。
