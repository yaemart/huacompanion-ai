# 旧报价与 AI 草稿另存新版

「方案报价与服务履约」里，旧报价可选「以新格式另存一版」。系统带入原费用、币种、有效期和条款，请逐项选择实际服务方并核对日期。原稿、原审核历史和原总成本保留。主管可在新稿里单独填写分项成本。

AI 结果生成后尚未采纳时，选「整理此结果为报价草稿」进入同一编辑器。已经采纳的 AI 报价从报价版本另存。保存前须确认已逐项核对 AI 草稿。新版保留来源，审核从待送审开始。旧格式草稿须另存后才能送审和发出。

## E7、E8 亲测

1. **E7。** 用运营打开 `DEMO-INQUIRY-2`，从旧演示报价另存。核对预填的条款、数量和金额，选择服务方，保存。刷新后应同时看到原版和新版，新版显示「待送审」。配置虚构公司主体后，可提交审核。
2. **E8。** 用主管核对新稿并填写意见，按需要逐项确认后批准。换运营发出新版。核对旧审核记录仍可查看，运营账号看不到内部成本。

本批无需新增迁移或环境变量。AI 浏览器验收使用隔离虚构结果。真人新人计时和实体手机待验。 [本地测试指南](local-testing-guide.md)
