# 本地亲测 · 订阅名单 CSV 导出

管理员在订阅管理中应用主题和状态筛选后，可点「导出筛选结果 CSV」。文件包含全部匹配记录，每条记录仍代表一个邮箱对一个主题的订阅。导出列为邮箱、主题、语言、状态及申请、确认、退订日期，并注明统计截至时间。日期与时间按北京时间显示。

文件采用带 BOM 的 UTF-8 和 CSV 公式转义。导出前重新核对有效管理员身份，记录导出人、时间、筛选及条数。审计保存失败时，下载会被拒绝。

## 亲测步骤

1. 启动 `npm run demo`，另开终端执行 `npm run test:subscriptions -- --preview`，按终端提示获取临时管理员账号。
2. 登录 [3186 后台](http://127.0.0.1:3186/admin)，进入订阅管理。全部主题应有 28 条虚构记录，点导出后核对 CSV 含 28 条数据，包含第二页记录。
3. 选择「政策更新」和「已订阅」，点「查看」应用筛选，再导出，应有四条。用 Excel 打开核对中文、日期和截至时间。
4. 在后台「操作记录」核对导出人、筛选和数量。退出后用临时运营账号登录，应无法导出。按 Ctrl+C 清理临时库和账号。

`npm run test:subscriptions` 会额外验证公式开头的旧数据被转义、越权和撤权被拒，以及审计提交失败时不会返回名单。群发继续留在停止点 C。
