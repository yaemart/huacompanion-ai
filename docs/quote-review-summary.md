# 报价二审第一批

人工报价保存后进入「待送审」，点「提交审核」后请另一位有权限的主管或管理员核对。审核意见必填，可以通过或退回。通过后再点「发出此版本」。从 AI 结果采纳或修订的报价仍进入待审核，发出时执行同一规则。

起草人不能审核自己的报价。管理员确需例外时，必须勾选例外并填写原因，审核记录会留存。批准只适用于审核时的那一版。另存新版本、改动草稿内容或旧批准无法核对版本时，要重新审核。已有已发出、已确认的报价保留原状态和客户确认流程。

## 本轮可以测的场景

1. **E7 送审。** 在演示站用运营打开 `DEMO-INQUIRY-2` 的服务单，展开「新建报价版本」，填写虚构服务范围、费用和北京时间有效期，保存后点「提交审核」。检查待审核时「发出此版本」不可用。
2. **E8 审核。** 换同组主管打开同一服务单。核对留空意见不能审核，填写意见后可通过或退回。运营起草的报价可由该主管审批。既有演示草稿由主管起草，若用它练审核，应换管理员。主管可见原整单内部成本，运营看不到。
3. **审核后发出。** 换回运营，刷新后发出该虚构版本，检查显示「待客户确认」。若选择退回，请到「新建报价版本」按意见修订，再送审。

普通重启即可，原演示数据保留。费用项主体、私有分项成本、逐项确认、毛利视图和预置待审样例属于后续批次。E7 和 E8 的新人独立计时及实体手机体验待验。 [本地测试清单](tasks/local-test-checklist.md)
