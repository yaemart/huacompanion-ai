# 咨询回复模板 · 本地亲测

合并后先停演示站，配套备份数据库和图片，请开发者应用并登记迁移 `20261114_080000_inquiry_reply_templates`，然后重新启动。已有演示资料无需重置。

1. 用**管理员**登录，在「业务运营 → 回复模板库」创建一条「演示行程确认」，分类选「咨询回复」。分别填「您好，请提供预计到达日期。」和「Hello, please share your expected arrival date.」，保持「供咨询页使用」勾选并保存。可再用同样方式建一条「报价说明」和一条「服务确认」。
2. 用**运营**打开自己负责的 `DEMO-INQUIRY-2`。在「处理操作 → 回复模板」点「读取回复模板」，选「咨询回复」、English 和刚创建的模板，再点「插入模板」。把正文改成适合这次虚构咨询的文字，点「复制回复」，粘贴到本机记事本，核对是修改后的英文。
3. 换中文或换分类。现有草稿会保留；再次插入时须确认替换。回管理员模板库关闭「供咨询页使用」，重新打开咨询并读取，确认该条不再出现。运营账号只可在自己有权处理的咨询中使用模板。
4. 用手机从局域网打开演示站时，如果系统未允许自动复制，页面会选中文字，可长按手动复制。回复草稿只在当前页面保留，离开前请先复制。 [手机局域网步骤](local-testing-guide.md#临时用同一wi-fi手机访问)

模板用于员工起草回复。客户沟通仍由员工在所用渠道完成。没有新增环境变量。
