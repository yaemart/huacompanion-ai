# 本地亲测：按钮暂不可用时的提示

内容工作台、政策事实和公开说明、报价审批会在按钮旁显示当前限制和能做的下一步。例如先保存草稿、请另一位审核员处理、填写审核意见、勾选签约方和收款方差异。手机端也可以直接阅读提示。

## 合并后怎么测

同步代码后重启 [本地演示站](http://127.0.0.1:3100/admin)。这批沿用当前演示数据和账号。

1. **E5 内容送审。** 运营打开已保存的虚构指南，修改摘要后立即看「提交已保存稿审核」，按钮旁应提示先保存当前修改。保存完成后，提示消失，可以送审。
2. **E1–E4 政策审核。** 新建一条虚构政策，先不保存，送审旁应提示先保存草稿。打开一条已送审的指南或政策，对照编辑、审核人和管理员账号，查看待审锁定、本人回避、复核勾选和退回原因提示。政策说明依赖已发布的共用事实时，提示应指向事实。
3. **E7–E8 报价。** 运营打开一份已送审的新格式虚构报价，「发出此版本」应提示等待第二人审核。主管打开同一份，先看「审核通过」旁的意见提示，填写意见。若该报价有主体差异或代收勾选项，按提示逐项确认后再看按钮。
4. **手机。** 打开政策或报价审核区，核对按钮旁的原因一眼能看到，长句可换行。

如需新建测试报价，先由管理员确认演示库已配置虚构的华伴公司主体。只测试提示时，填写资料或勾选确认即可验证按钮变化。
