# 新版报价的逐项审核与发出

运营保存新版报价后，可以提交审核。主管核对报价时，签约方和收款方不同的费用项单独确认。若同一项由华伴代收，还要单独确认已与服务商约定转付。两项都勾选、填写审核意见后，才能批准整份报价。起草人自审仍适用现有管理员例外规则。

发出前，系统重新检查公司主体、服务商及收款方资格、有效期和当前版本的审批记录。代收关闭时，已批准的代收草稿也会被拦住。已发出报价保留当时的三方主体和公开代收说明。客户页可查看这些信息，内部原因、逐项确认记录及成本只在有权限的员工端可见。

## E7、E8 可以怎么测

1. **E7 运营送审。** 用虚构资料填写已配置的公司主体。在 `DEMO-INQUIRY-2` 的服务单新建新版报价，选择或手填服务方，填写一个不同的签约方及差异原因。保存后提交审核，核对状态变为「待审核」。
2. **E8 主管确认。** 换主管填审核意见。先留空主体差异确认，核对「审核通过」不可用。勾选后批准。再换运营发出，核对「待客户确认」，并检查成本只对有权限的角色显示。
3. **代收仅在隔离环境演练。** 管理员可在「内容中心 → 公开公司信息」看到默认关闭的「允许华伴代收第三方款项」。开发者使用独立测试库演练了两种确认缺一不可，以及审核后关闭代收会阻止发出。

已有演示库需先配套备份，再由开发者应用 `20261113_110000_quote_line_review`。原报价保留。后台可配置的对客说明、旧未发出稿和 AI 稿的新版转换、毛利视图待后续。真机和新人计时待验。 [本地测试指南](local-testing-guide.md)
