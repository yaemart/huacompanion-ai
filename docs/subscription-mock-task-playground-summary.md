# 已占位本地模拟任务：领取、尝试与结果演练

获独立主题授权的主管打开本人活动后，可以选择已占位的虚构任务，依次领取、开始一次本地尝试、记录结果。结果不会发送邮件，也不代表供应商接受或真实送达。余额和占位仍由既有服务准备，本轮没有新增准备入口。

## 怎么亲测

使用Node24.22.1，保持本机演示数据库运行：

```sh
npm run test:subscriptions
```

脚本在随机库自行准备虚构余额、占位及权限，运行28组订阅回归并清理。末尾应看到本地模拟演练接口通过，覆盖等待、重试、待核对及审计失败回滚。

浏览器可使用 `npm run test:subscriptions -- --preview --isolated-browser` 启动独立生产预览。等构建和Ready完成，再用临时账号进入后台。管理员授予主题权限、主管保存/模拟确认/冻结后，还须由既有本地服务在本次随机库准备余额和占位。默认预览不自动准备这些任务；未准备时页面会显示暂无已占位任务。准备后重新打开活动，切勿为亲测改原演示库。

## 页面操作

1. 选择当前版本的已占位任务，点“领取所选任务”。领取不计尝试。
2. 点“开始本地尝试”才记一次。开始成功前不能提交结果；凭证仅保存在当前页面，刷新会丢失。
3. 选择模拟完成、临时失败、429限速、结果不明或永久失败，再记录结果。429可填等待秒数，原服务仍取至少30秒起的指数退避。
4. 等待结束后重新领取同一任务，再开始下一次。最多5次、首次起23小时；结果不明、开始后租约过期或门槛耗尽进入待核对，没有清除或重置入口。
5. 点原“刷新状态”更新汇总。当前回执立即显示，汇总保留自己的统计时间，不自动运行任务。

未保存的选择、无效确认/来源、暂停或取消会阻止演练。结果不明时任务、结果及其他写入表单锁定，只能点“核实本次模拟操作”，核实会发送相同动作和输入。若领取已经保存但凭证丢失，核实可能只返回已占用，本页不会恢复凭证；未开始的租约到期后可重领，已开始者按原规则待核对。明确拒绝后按提示重新准备。
