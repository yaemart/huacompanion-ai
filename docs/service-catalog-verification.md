# 服务目录本地开发验收 — 2026-10-27

## 使用入口
- 服务商目录：/zh/providers
- 华伴服务项目：/zh/services/projects
- 服务商展示工作台：/content-center?kind=provider-profile
- 服务项目工作台：/content-center?kind=service-project
- Agent 读取说明：/api/public/catalog/docs

## 操作流程
1. 在业务后台维护服务商申请，确认核实／签约状态及公开展示许可。
2. 在服务商展示工作台新建公开档案，管理员按名称关联内部服务商；填写城市、语言、服务能力和实际核验事项。
3. 在项目工作台维护服务范围、计价方式、准备材料、流程和变更规则；选择按需求安排或指定履约方。
4. 保存草稿、提交审核。管理员检查文字、图片、价格及核验信息，勾选检查后发布。中英文分别审核。
5. 客户通过目录详情进入华伴需求表。后台客户咨询保存来源标题、公开编号、发布版本及当时的内部履约关联；按原有负责人和状态流程跟进。

停用或撤销许可会隐藏对应服务商及仅被该公开档案引用的图片；指定项目暂停咨询。服务商恢复后，项目需重新审核发布。单语言下架不会暂停另一语言仍有效的项目。

## 验证记录
31 项单元测试通过。目录集成覆盖私有字段隔离、许可检查、关联需求保存、重复提交、暂停与恢复、单语言下架。原业务 13 项集成检查、内容发布及 AI 任务回归通过。

目录 HTTP 测试覆盖详情、JSON-LD、来源预填、真实本地提交、幂等冲突、下架媒体、站点地图、语言隔离与无效参数。原内容 HTTP 测试及 8 项业务 HTTP 检查通过。生产构建／类型检查、空数据库迁移及备份恢复通过。

浏览器检查桌面／390px 手机目录、后台结构化字段、发布状态筛选；失效来源明确阻止表单，主动移除后可重新填写一般咨询。网络失败后的来源切换由组件身份回归测试覆盖，未模拟浏览器断网。

## 当前边界
这是本地版；未上线 Replit，未接通真实报价、支付或实时档期。通知仍为本地待配置任务。Agent 仅公开读取和进入预填表单，不具备独立写入、自动发布或直接联系服务商能力。

没有自动发布真实服务商或服务项目。测试使用明确标注 Fictional/Test 的虚构资料，验收后全部下架或暂停；目录为空时表示等待真实资料审核。
