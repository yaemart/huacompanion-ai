# 本地模拟任务状态：本轮亲测

获独立主题授权的主管打开本人活动后，可查看原冻结名单的本地模拟任务汇总，点击“刷新状态”更新数量和统计时间。刷新保留当前未保存的政策选择，不会领取、重试或重置任务，也不代表邮件送达。

## 怎么亲测

使用Node24.22.1，保持本机演示数据库运行：

```sh
npm run test:subscriptions -- --preview --isolated-browser
```

等待生产构建和Ready后打开3186后台，使用终端指定的临时账号。管理员授权主管后，以主管新建活动、测试确认、冻结名单，再看页面下方“本地模拟任务状态”。默认只有冻结任务，尚未接入页面的占位/尝试仍需由原服务演练；本轮没有这些操作按钮。自动化回归会在独立随机库准备所有状态，无需手动改原演示库。

## 怎样理解状态

- 未占位、待领取、已领取尚未开始、本地尝试中分别统计准备阶段。
- 等待重试显示最早重试时间；时间已到只表示等待结束，继续处理仍须核验当前权限、来源、同意及暂停/取消状态。本页不会自动运行任务。
- 结果不明、开始后租约到期、五次或首次23小时门槛耗尽显示待核对。尚未持久更新的超时在读取时推导，刷新不写库，没有清除待核对入口。
- 永久失败只代表该任务的本地停止；模拟完成不代表供应商接受或真实送达。已取消活动仍保留完成、失败和待核对历史。
- 保存新版后仍标明原冻结名单的版号，不混入新版本任务。来源/配置变化、暂停或取消不遮蔽历史。

刷新失败会保留上次统计并提示核对时间。接口只返回数量、版号和时间，不返回邮箱、逐人记录、正文、任务键或凭证。非本地环境、无授权、跨主管和旧版本请求均拒绝。

## 验证与环境

运行 `npm run check` 和 `npm run test:subscriptions`。新增状态回归覆盖权限、同源/输入、各分类、过期边界、原批次及读取前后全库指纹不变。客户端回归覆盖成功摘要、无效JSON、畸形成功、总数不一致、网络失败及权限提示。实际结果与浏览器范围以progress及PR的最终记录为准。

Ctrl+C退出预览会清理随机库和构建副本。本批没有新增迁移、依赖或产品环境变量，原3100/55442和图片保留。PR97既有尝试表迁移仍须按原交接备份后应用；未升级的演示库不因此自动升级。真实邮件、AI、语音、通话和正式评分保持关闭，人工核对/调度及真实发送仍属后续。
