# AI 服务方案与报价草稿

## 员工操作

在 `/business-center` 打开权限内服务单，使用“AI 服务方案与报价助手”。

1. 选择七种目标语言之一，填写已核实、去除身份信息的需求摘要。不要粘贴客户姓名、联系方式、证件、详细地址、健康资料或完整聊天。
2. 填写已核实费用项目、数量、单价、币种及有效期。模型只写方案文字；费用明细来自员工输入，总额由服务器计算。模型不能自行增添价格或费用项目。
3. 确认摘要已去除敏感资料后提交任务。未配置模型时保存为“模型未配置”，不调用外部网络、不生成模拟内容。配置后仍需员工点击“重新排队”。
4. 生成成功后查看原稿、问题与风险提示，点击“整理此结果为报价草稿”。员工可修改文字和费用，处理待核实事项后保存。资料已变化时必须重新生成，不覆盖新资料。
5. 保存后为“待审核”报价，客户看不到。主管或管理员填写审核意见，明确通过或退回；生成或采纳本身不构成审核。
6. 通过后，员工另行点击“发出此版本”，客户才能查看。退回的版本不能发送；在助手中再次整理已采纳任务会以最近版本为基础保存新版本，保留 AI 来源且重新进入待审核，不继承旧审批。

审核要求是单独的人工作业，不强制生成者和审核者为两个不同自然人；普通运营无主管权限时不能审核。审核通过不代表资源已预订，原有客户确认与履约资源确认仍分别进行。

任务与原稿、未发出报价、审核意见不公开。客户 DTO 不含 AI 任务、内部成本或审核备注。报价定价和事实真实性仍由员工负责，程序的格式检查不能代替业务核实。

## 本地配置与关闭状态

默认环境不配置下列值，因此真实 AI 关闭：

```dotenv
BUSINESS_AI_ENABLED=false
BUSINESS_AI_ENDPOINT=
BUSINESS_AI_KEY=
BUSINESS_AI_MODEL=
BUSINESS_AI_DAILY_TOKENS=0
```

启用需同时设置 true、HTTPS 网关地址、密钥、模型名及正整数每日令牌额度（上限 10000000）。这些是本项目兼容网关协议，不是任何模型供应商的直接 API 地址承诺；外部供应商适配服务仍需选定、配置和实际验收。不得把供应商原生响应直接当作下列协议已兼容。

任务由 `npm run workflow:worker` 处理。每轮领取一个任务，使用数据库事务和租约避免重复领取；网络调用在事务外执行。默认 60 秒超时、120 秒租约；开始及结束均检查租约、原员工当前权限、服务单修订和咨询更新时间。采纳前再次检查创建者权限。取消、关闭开关或资料变化时不采纳迟到结果。

输入字节数加保守余量作为令牌预算预留，返回用量超过预留时记入更高值；失败、取消、超时不释放可能已消费的额度。不承诺精确费用核算或供应商账单硬上限。超时及失败不自动重试，员工核实后才能明确创建新任务。同一个服务单最多保存100个任务。

## 网关契约

POST 配置的 HTTPS 地址；`Authorization: Bearer <server secret>`；禁止重定向；响应上限 64000 字节。

请求：`{model, input:{instructions, brief, locale, currency, lines}, maxOutputTokens:4000}`。输入没有咨询原文、客户身份、联系方式、内部成本或系统凭据。员工填写文本仍需自行去除隐私，启发式检测不能保证识别所有敏感资料。

响应：

```json
{
  "result": {
    "title": "方案名称",
    "scope": "服务范围",
    "included": "包含事项",
    "excluded": "不包含事项",
    "terms": "变更和取消规则",
    "questions": ["需要人工补充的事实"],
    "warnings": ["需要人工核实的风险"]
  },
  "usage": { "inputTokens": 100, "outputTokens": 200 }
}
```

result 不允许附加字段、价格、自动发出指令。标题最多200字符，四段文字各4000字符；问题及提示各最多20条，每条500字符。所有字段通过验证后仍只保存内部原稿。

## 验证与运维

`npm run test:business:ai` 使用实际本地数据库和注入的测试模型，不访问真实供应商。覆盖关闭、来源与身份隔离、人工修改、审批限制、报价修订重审、取消、超时、额度、过期租约、失效权限和迟到结果。不要在生产库运行；测试保留虚构记录。应用启动后执行 `npx tsx tests/integration/business-ai-http.ts` 验证真实 HTTP 登录、跨站拒绝、任务幂等和关闭状态。

数据库迁移包含 `20261031_054202_business_ai`。迁移前备份。`npm run backup:test` 已增加业务、AI任务、客户、待办、内容复核和客服记录的恢复比对。新增迁移回退要求恢复匹配备份，不向下删除审计数据。

外部账号未配置不阻塞人工业务流程：员工仍可正常创建人工报价、处理咨询、客服、内容与待办。真实模型、邮件、语音和通话、Replit/AWS、手机 App 商店发布均不因本功能完成而自动开通。
