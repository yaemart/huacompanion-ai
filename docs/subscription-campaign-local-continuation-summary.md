# 同一活动改版后的本地续发

已核对 PR112 合并后的 main。本批增加内部本地服务：负责人保存同一活动的新版后，必须重新模拟测试并逐语言确认，才能把原名单中从未尝试、仍符合资格的虚构邮箱任务绑定到新版。名单不补新人，原冻结版本保留。

已经尝试、完成、取消、失败或待核对的任务保留原记录。任何尝试行或完成证据都会排除；尚有有效领取时首次续发整体拒绝。过期但未开始的原占位可以续用，旧领取凭证不会恢复有效。

续发本身不占位、不扣余额、不领取或尝试。同一版本重复调用返回原收据，六次并发只建立一次范围。新版本继续使用原来的权限、资格、额度、共用尝试预算、全站每秒一次、确认/资料邮件优先和重试规则。原任务绑定记录与审计同时提交，提交失败整体回滚。

随机测试库用 16 项原任务验证仅 4 项进入第二版；其余历史、取消及资格失效任务保持不变，新订阅者不加入。第二版实际尝试保存新版正文；第三版与退订事务同步后仅剩 2 项继续绑定，两个独立 CLI 进程分别模拟完成，第二版已经尝试的正文、唯一键、次数和重试记录保留。

完整 check 463 项单元测试及 34 组订阅集成全部通过。独立复核指出的设置并发问题已先复现再修正；新版确认和续发提交现在与管理员设置保存同步。完整检查结果见 [实施记录](progress.md) 和 [交接](handoff.md)。本批没有新页面按钮或 HTTP 动作；既有 worker 仍明确指定负责人、活动和版本。后续再接后台操作与说明。没有真实发送、清除待核对或强制重试。

新增迁移 `20261124_090000_subscription_campaign_continuation`，只增加三个可空内部绑定字段及约束、索引；原数据默认空值，有续发记录时拒绝回退。仅在随机库迁移验证，原演示数据库未升级。将来应用前须备份、停止 Web/worker、执行迁移后重启；无新增环境变量或依赖。

本批没有浏览器或真人验收。原始日志只在本机忽略目录 `.local/subscription-campaign-local-continuation`，未上传 PR 附件。PR113 由用户决定合并。
