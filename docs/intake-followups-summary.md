# 本地编辑体验：只能追加的跟进记录

咨询与服务商申请都有“内部跟进记录（只能追加）”。填写后点“追加跟进（立即保存）”，系统自动记录员工和北京时间。已有记录只能查看，不可改写或单独删除。旧备注原文显示为第一条；旧时间和记录人没记过的，明确显示“未记录”。

跟进独立保存，其他未保存的资料仍留在表单里，再用顶部“保存”。跟进使用自己的记录时间，不改变上方资料修改时间；重试同一次提交不会增加重复记录。管理员显式导出内部备注时包含完整时间线；普通导出继续不包含。
