# 本地亲测：订阅数据与确认凭证（H 2.2a）

订阅以规范化邮箱和主题为单位。每条记录保存语言、同意时间、隐私版本、来源路径和可选合作方编号。新记录从待确认开始。确认凭证有效 24 小时，数据库只保存摘要。重发会使该订阅的旧版本失效，确认和凭证核销在同一次事务内完成。后台订阅记录和凭证集合仅供服务器内部访问。

## 在 Mac 上亲测

同步代码，使用仓库指定的 Node 24.22.1。按[本地测试指南](local-testing-guide.md)启动演示环境，保持本机演示数据库运行。在项目目录的另一个终端执行

```sh
npm run test:subscriptions
```

命令会在本机演示数据库进程中创建一个随机命名的临时库，应用迁移，用 `example.invalid` 虚构邮箱跑完再清理。直接沿用原有演示数据，无需重置或配置邮件。最后两条 `PASS` 分别确认：

1. 空表可以回退并重迁移。旧表指纹相同，有订阅数据时回退会被拒绝。
2. 待确认不生效。过期、旧版本、跨用途和已使用的凭证被拒绝，同一凭证并发使用只有一次成功。匿名请求无法从集合列表或记录详情取得邮箱。

本批使用命令行验收，现有 C、E 场景清单无需新增界面操作。迁移 `20261117_120000_subscription_data` 新增两张私有表。测试命令自动迁移临时库。日后需升级现有环境时，先配套备份数据库与图片，再按交接运行迁移。
