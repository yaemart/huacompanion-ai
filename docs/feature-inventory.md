# 第一版功能清单与试运行开关

当前需求以[流量入口分阶段任务书](traffic-entry-task.md)为准。下表复用既有基础的验证状态；阶段1.1a已开始本地数据契约/类型验证，后续集合与工具尚未实现；所有新公开入口仍未启用。英文为默认首页，公开语言默认顺序为 en,zh。

更新：2026-11-01。功能冻结；仅收敛已存在模块，不新增供应商、支付、自动派单或模型能力。试运行范围为中英文官网、两个表单、中文后台、内容发布、咨询／服务商管理、基础报价、站内通知、经营统计和权限导出。

验证状态只使用“已验证 / 已实现未验证 / 未实现”。“已验证”指已有本地自动化或本地人工验证证据，不代表真实邮箱、模型、域名、托管、试运行数据库恢复或云端低权限验收已经通过。高级模块即使本地测试通过，当前也均为**已实现，未启用**；本地注入适配器不等于外部服务已经接通。

## 已有数据库的一次性收敛

仅修改源码默认值不会把已有数据库中的 true 改成 false。新增迁移 `20261101_030726_trial_feature_defaults` 只将 `support_settings.text_chat` 的数据库默认改为 false，保留旧记录。已存在的本地／试运行库由操作者显式运行：

```sh
npm run trial:configure
npm run trial:configure -- --apply
```

第一条只预览；第二条在一个事务内关闭全部客服功能开关、客户中心和工作流邮件，并写入 `audit-events`（仅保存相关布尔开关的前后值，无密钥）。不删除或修改业务内容、客户账户、咨询、服务商、报价或员工权限。只允许 `APP_ENV=local` 或 `trial`；`BUSINESS_AI_ENABLED=true` 时拒绝执行，先在部署环境设为 false。写入前与正常管理员设置操作串行，审计前值通过真实 PostgreSQL 三组管理员并发写入测试。它不是启动钩子，不会每次重启重置后续获授权的开关。CLI 不修改环境文件；`SITE_LOCALES=en,zh`、模型环境配置、`INTAKE_ENABLED=false` 和 `SEARCH_ENGINE_INDEXING=false` 仍由操作者确认。

试运行“纳入范围”不等于现在开放真实收集。local 模式仅用于虚构数据的本机测试；trial 仍受 HTTPS、隐私版本和 `INTAKE_ENABLED` 总门控制。不得用本地成功结果替代[部署验收](trial-deployment.md)中的真实邮件、数据库／图片恢复、网关、低权限和域名检查。
