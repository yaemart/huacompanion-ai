# 员工每日站内摘要 · 本地亲测

每个员工可在「通知与待办」自行勾选「每日摘要」。开启后，新建服务单、更新对客进展、完成服务或转入售后的通知，在下一次北京时间 09:00 合并显示。09:00 起产生的普通进展进入次日摘要。摘要只在站内显示。紧急通知、待办和客户通知照原流程处理。每个员工只能在自己的通知页查看摘要中的有权记录。

## 合并后怎么测

已有演示库先停站，由开发者配套备份数据库和图片，应用并登记 `20261115_080000_staff_daily_digest` 后再启动。新建演示库会应用此迁移。已有演示数据可继续使用。

1. 用演示运营账号登录 3100，打开[通知与待办](http://127.0.0.1:3100/workflow-center)。勾选「每日摘要」，刷新确认仍勾选。另用演示主管账号确认其选择独立，随后切回运营。
2. 从[方案报价与履约](http://127.0.0.1:3100/business-center)打开自己负责的虚构服务单。如果还没有，用自己负责的演示咨询创建一个。在「客户可见进度说明」分别保存两次不同的虚构进展。刷新通知页，两条更新应等到下一次 09:00。把自己负责的虚构咨询的「下次跟进」改为一个新的时间并保存，刷新通知页，核对「客户咨询待跟进」立即出现。
3. 过了北京时间 09:00 刷新通知页。展开相应日期的「每日摘要」，核对两条进展在同一组，可以打开对应咨询并逐条标为已读。切换主管或审核人账号时，该组摘要只属于原收件人。
4. 取消勾选，再保存一次不同的虚构进展。刷新确认新通知直接显示，先前排定的摘要按原时间显示。

本轮作为 E10 的通知补充检查。无需开启 worker 或邮件。自动测试已模拟 09:00 前后和跨日，手动计时请在本轮问题表记录账号、操作时间及截图。
