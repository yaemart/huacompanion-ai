# 来源核实日期｜本轮小结

政策、就医、签证内容送审和发布前，须填写来源核实日期。日期须有效，且不能晚于北京时间当天。

- **入境政策**在共用事实页填写官方来源和「最后核实日期」，中英文共用一次。旧政策工作稿的送审入口也会检查该日期。
- **文章和资料**在「资料来源」填写每条来源的人工核实日期。就医板块、已有的相关内容和免签工具关联稿件会自动识别。其他涉及这三类主题的稿件，请在「资料主题」选政策、就医或签证。
- 未核实完可先保存草稿。旧待审稿缺日期时，审核人可退回，请运营补齐再送审。已发布版本继续显示，普通内容的日期仍可选。

## 合并后怎么测

- **E1／E2 附加检查**。用运营账号打开[共用政策事实](http://127.0.0.1:3100/content-center/policy-facts)，用虚构政策保存一份空核实日期的草稿。尝试送审应提示补日期。补日期后先保存，再送审。
- **E5 附加检查**。在[来华指南工作台](http://127.0.0.1:3100/content-center?kind=guide)把虚构指南选为「就医」或「签证」，添加虚构来源。缺日期时送审应指出具体哪一条。补齐所有来源日期后再保存、送审。

三类虚构稿件已在隔离站实际验证。无需重置或迁移。真人新人计时和实体手机仍待验收。
