# 报价签约方与收款方

在服务单打开「新建报价版本」，勾选「录入新版费用项主体与成本」。选择华伴自营时，经营模式、签约方和收款方由公司资料带入并锁定。外部或手填服务方的签约方可以修改。收款方默认是实际服务方，也可从权限内已核实或已签约的服务商中另选。

签约方和收款方不同时，界面会要求填写差异原因。保存后，员工可在报价版本里查看这条原因。客户接口只返回三方名称。服务端重查收款方资格，拒绝华伴代收，包括使用已存自营报价中的旧公司名称，或要求将外部费用项改成华伴统筹的请求。

## 本轮可以测的场景

- **E7 录入。** 用运营打开 `DEMO-INQUIRY-2` 的服务单，选「华伴自营」，核对主体锁定。再选外部服务方或手填虚构服务方，填写一个不同的签约方。试着留空原因保存，再补上原因并保存。刷新后核对三方和原因。若有权限内的已核实或已签约服务商，可在收款方下拉框另选一项。
- **E8 成本权限回归。** 换主管看同一服务单，分项成本继续按权限显示。换回运营，核对三方和内部原因仍可见，成本栏隐藏。

本轮验收到保存草稿。逐项审核、发出、对客页面和毛利视图排在后续批次。代收设置随逐项审核接入，真实启用仍以律师确认后由用户决定为准。
