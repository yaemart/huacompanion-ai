# 月度评分卡试行 · 本地亲测

本批提供规则配置、员工观察记录和跨月复核更新。前三个完整北京时间自然月为试行期，只记录指标、样本、待定及复核结论。第四个月起仍是记录模式，正式评分须另行确认。

## 合并后测试

已有 3100 演示库先配套备份数据库和图片，补齐此前缺少的已合并迁移，再应用 `20261115_210000_staff_scorecard` 后重启。新演示库首次启动会自动应用。保留现有演示数据。环境变量和种子沿用。

1. **管理员配置**。从后台首页点「个人业绩与月报 → 评分规则」。展开运营模板，核对首响 25%、跟进 45%、投诉 30%，以及首响达标 1,440 分钟。首次按主要角色预填人员分配，可手动调整。给多岗位员工配置兼岗模板时，先补齐该模板到 100%。
2. **保存和安排**。选择下一个完整北京时间自然月作为试行开始月，填写调整原因，点「保存草稿」。再填写安排原因，点「安排观察规则」。检查已安排的月份和版本，试行开始月会锁定。把运营权重改成总计 101% 再保存，应显示校验提示，已安排版本保留。
3. **员工权限**。换运营或主管登录，从后台打开本人月报。员工页无「评分规则」入口，也不能打开规则页面。试行开始前，当前月提示尚未安排观察规则。到生效月份后，查看本人实际值、样本及待定状态。管理员可切换指定员工对照。
4. **待定和跨月**。运营登记虚构投诉，经有权限且未涉事的主管确认归属后，在个人月报观察项应看到「待定」。发起申诉，再由另一位有权限且未涉事的人复核。跨月时回到首次确认月查看更新与复核时间。自动集成测试用虚构日期覆盖了跨月边界、第三个月结束以及第四个月仍无个人分数。

后台规则页中的假设值示例只使用填写的目标值和零分界线。个人观察记录展示样本覆盖权重。没有计划发布日期的指标显示「缺少计划数据」，提前撤销的复核提醒不计样本，能明确关联到咨询的人工回复计入处理样本。同一员工的关联质量事件在兼岗模板中去重。
