# 服务商申请：主管有原因审核

主管现在可在本人团队的数据范围内，点击“核实通过／签约／暂停”，每次先写原因。
管理员也可使用同样按钮；普通运营仍只能整理资料和追加跟进，不能审核或批准公开展示。
审核原因、操作者、时间和前后状态均留在管理员的操作记录中。

核实或签约不会自动公开。暂停会撤销展示许可；之后重新核实也不会自动上架，
仍需管理员另行许可。暂停继续沿用原有指定服务项目停止接单规则，恢复核实不会恢复已停项目。
按钮只记录合作进展，不签署合同或发送对外消息。

有未保存资料时先用顶部保存，再审核。失败会保留原因；审核不刷新整页，未提交跟进保留。
补上服务端过期保护：若其他人已改资料，审核和顶部保存都会拒绝覆盖，并提示先保留输入、刷新核对。
审核成功后可继续正常保存，不会把自己的审核误认作他人修改。

本机3100普通重启后，用主管打开“服务商入驻与合作 → DEMO-PROVIDER-1”，
先看空原因时按钮不可用，再填写虚构核实原因并核实，确认“允许公开展示”仍未勾选。
