# CRM A1b一页中文小结

员工内部服务现在可把一条咨询归入一个客户档案，核对证据后撤销并重新关联。
客户与咨询都须当前有权访问，新关联必须同团队。每次操作留版本与审计，重复提交只记一次。
服务单自动沿咨询归属展示，保留原单，不复制、不创建第二套客户关系。

旧客户对外访问授权保持不变：只要咨询仍有活动旧授权，CRM撤销就被阻断，不能强制收回授权。
有活动关联的客户不能存档，即使其中的咨询已转交给其他员工。重关联不向新客户透露前客户资料。
列表只返回授权咨询和服务单编号、标题、阶段，不输出内部成本、安排、邮箱或证据正文。

本批没有新页面、HTTP入口或邮件。A2员工界面在本PR合并后另批，其他CRM阶段继续后置。
新迁移只建私有关系表，不回填旧数据；有任何关系历史不能直接回退。
使用CRM独立worktree与PG15.20集群，原演示与私有归档不操作；无新依赖、产品环境变量或.env变化。
