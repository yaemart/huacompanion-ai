# 入境政策数据、审核与投影（1.1a–1.1d）

状态：数据契约、私有集合/版本、审核事务、后台表单、仅草稿种子和正式快照投影已本地验证。编辑复用内容工作台，需开启后台开关和板块授权，默认隐藏。1.2纯查询及1.3a/b SSR/浏览器查询已本地验证；1.3c FAQ/本机性能与可访问性已验证，1.4正文状态横幅已验证，下一步1.5站内复核提醒，不代表真实政策已核实或上线。

## 当前已实现

`src/lib/immigration-policy.ts` 从Payload生成的`ImmigrationPolicy`字段派生完整发布输入`PolicyPublicationData`、白名单公开输出`PublicPolicyData`，以及无网络/数据库/时钟副作用的校验与投影函数。校验仅用于完整发布数据；集合允许事实待补的部分草稿，审核服务分别处理。关系在发布契约中收窄为员工ID，口岸数组行规范化为label字符串数组；并非把带关系的原始集合记录直接公开。内部备注兼容Payload的null空值。

字段为国家代码及中英名称、四类政策、最长停留天数、生效/截止日期、口岸区域条件、官方来源、最后核实日、核实人员工ID、公开说明和内部备注。截止可为空，公开投影统一为null，不表示政策永久有效。

日期采用YYYY-MM-DD日历日，调用方显式传入中国当天日期；不取访问者浏览器时区，不把UTC时间戳截取当作中国日期。校验拒绝不合法日期、截止早于生效、未来核实日、不合法停留天数/核实人、带账户信息或非HTTPS的来源URL；240小时过境必须填写口岸/区域条件。不会据此计算240小时出境期限或承诺入境资格。

国家代码当前校验两位大写形状，**不等于确认ISO代码已分配**。国家代码实际归属、来源是否官方、政策条件是否准确都必须由工作人员核实后审核；本轮不下载国家表、不请求官方站点，也不写死政策数据。测试中的国家、来源和日期组合完全为虚构夹具。

公开投影显式列字段，排除核实人、内部备注以及输入中所有额外字段，复制口岸数组避免通过返回对象修改输入。该函数不验证调用者身份或发布状态；后续公开读取必须先从正式快照读取并检查开关，不得把草稿传入这个函数就视为可以公开。

## 集合与工作流映射约定

1. `ImmigrationPolicies` 是唯一的结构化政策录入主记录，包含核实人及内部备注并保留版本；不允许绕过服务直接CRUD。1.1b已生成真实Payload类型，使用Pick/NonNullable派生契约，未手改生成文件或保留重复Schema。
2. 既有 `content-drafts` 承载政策的工作流身份、贡献人、审核状态和修订号；其JSON正文只引用政策主记录及政策修订，不作为第二个可独立编辑的政策字段副本。政策字段保存与工作流修订在同一内容事务中完成；提交后锁定对应政策修订，后续编辑走原退回/重提流程。
3. 审核发布时在同一事务重新核对主记录修订、范围权限、核实信息、来源及自审限制，再把公开白名单政策字段复制到 `content-published` 的正式快照。公开读取只读该快照；草稿改动、主记录新版本和内部备注不能改变已发布结果。下架撤销对应快照。
4. 内容工作台与政策集合界面都调用同一保存/提交/审核服务，不分别维护发布状态。未授权板块不自动授予现有员工；直接REST/GraphQL/Local API和历史版本访问均须受同一边界约束。
5. 公开快照沿用 `publicationRevision`/`publishedAt` 外层元数据；主记录ID、员工ID和内部备注不因关联关系被depth展开公开。本轮已有真实权限、并发和草稿隔离测试；1.1d再实现专用公开读取，不能通过通用内容列表暴露政策。

## 1.2 查询纯函数

queryImmigrationPolicies(input, policies, context)接收nationalityISO、arrivalDate，以及listPublicPolicies取得的正式公开投影。国籍允许去首尾空白及ASCII大小写转换，null表示“未列出”；日期严格YYYY-MM-DD有效日历日。context显式传入verifiedOnOrBefore，不使用隐式时钟。arrivalDate是查询日期，不能作为核实日期基准，否则历史查询会错误排除后来核实的政策。

返回matched/unconfirmed/invalid-input、字段错误代码、独立matches、中英notice及visaGuide/null，不回显国籍或入境日期。生效和截止含当天；空截止仍提示不代表永久有效。全部过期、未来尚未生效或未知国籍只说明“该日期的政策尚未确认”，不推测延期或断言必须办签证。

保留所有匹配政策及各自条件/来源/核实日期；按单方面、互免、其他、240小时过境排序，同类按核实日降序再按公开字段指纹稳定排序。停留时长不相加：普通方式stay.unit=days，过境方式hours/240，不返回maxStayDays或推算离境日期。warnings始终含conditions-unchecked；空截止增加expiry-not-stated，过境增加transit-itinerary-unchecked。中英提示见immigration-policy-query-copy.ts。

查询重新验证政策并拒绝携带任何非公开自有字段的对象，防止误传原始主记录/草稿；但纯事实对象本身不能证明已经发布。发布状态仍由正式投影负责，调用方不得手工剥字段后绕过工作流。visaGuide须调用方从listPublished中选择已发布指南，仅接受/en或/zh/guides/下的规范路径及有效标题；未配置/未发布返回null，不造链接。阶段1.3须实际选择签证指南，公开前须准备核实内容。

test:policies:query用本地虚构数据验证草稿/待审排除、发布匹配、改稿保留旧快照、下架及指南发布链路；已加入CI串行DB套件。纯测试在UTC、上海、洛杉矶子进程禁止隐式时钟/网络/存储并比较结果。本轮无页面、路由、数据库结构或实际.env变更；下一步1.3a SSR与无JS完整表格。

## 1.3c 正式FAQ与可访问性

## 1.4 正文政策状态横幅

在既有内容工作台选择“政策状态横幅”，填写政策稳定内容标识contentKey（由有权政策编辑提供，不是国籍代码或数据库数字ID），可选“明确标记为尚未确认”。保存、预览、提交审核、发布沿用文章原流程；修改未发布文章不会改变正式页。普通指南编辑不因此取得政策主表、历史版本或政策发布权限。AI候选内容不得创建横幅。

正文JSON为`{type:"policy-banner",text:"policy-content-key",policyUnconfirmed:true}`，待确认字段可省略。正文公开投影只保留白名单。仅消费同语言、同身份且唯一的active正式政策快照，历史依据只取同draftId、低于当前正式revision的最近一次publish审计快照，不读取政策工作稿或主表补事实。来源必须HTTPS且记录已核实；私有字段/损坏投影拒绝，数据库故障报错，不伪装“尚未确认”。

以中国日历日判断，截止0–30天（当天有效）优先“即将到期”；未生效/过期/无截止/手动待确认/缺有效正式数据则“尚未确认”。超过30天，只有前次正式发布与当前同国家/类型/生效日、有限截止严格延后且核实日不倒退，才显示“已公布截止日已延长”，同时列新旧截止、来源和核实日。没有证明的正常远期政策不显示，空截止不代表永久。任何状态都不保证入境或计算离境日期。

VISA_CHECKER_ENABLED=false时不读政策、不显示横幅或工具链接；只对en/zh且SITE_LOCALES包含的语言显示。已存引用仍可编辑/移除，关闭时不能新增类型选项。SSR请求内缓存相同引用，已打开页面保留加载快照，发布/下架后需刷新。无需JS即可读状态、来源和日期。

无迁移、新环境键、项目依赖或公网API。升级兼容旧正文，但旧代码不识别新块：多电脑先同步到此版本，再编辑含横幅文章；回退前备份数据库和媒体，不用旧版本重存新块。test:policies:banner覆盖真实审核；-- --http在开启生产站校验，-- --http --disabled在关闭站校验；test:policies:banner:render验证两语显示和编辑字段。[截图与局限](screenshots/policy-banner/README.md)。本步未重跑Lighthouse，不能沿用1.3c分数声称本页审计；现实政策、托管及B仍待验收。
