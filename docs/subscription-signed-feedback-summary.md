# 签名回执与本地整链路模拟

本批新增仅本地、默认关闭的POST回执入口，用Resend/Svix原始字节签名协议接收虚构事件。缺开关、缺密钥、非local、错签名、过期/过远未来签名、非法正文及超16KiB均拒绝；验签和解析在数据库初始化前完成。签名时间与事件时间分开，允许合法迟到事件用新签名重投。无新增依赖。

管理员内部演练服务先把模拟邮件ID绑定原尝试和邮箱摘要，回调只据服务端绑定查原任务；不信任回调里的任务号或tags。绑定不可换目标，原手工反馈仍需现职管理员。已处理消息按供应商命名空间及svix-id摘要幂等，同编号改目标、类型或时间拒绝；未绑定的相关事件返回可重试结果，不猜测关联。

送达、永久退信、投诉和供应商抑制分别处理。Temporary、Transient和Undetermined退信成功忽略，不自动当硬退信或重试发送。供应商抑制记录为独立provider-suppressed；无source_id的抑制只匹配已绑定过的虚构营销邮箱，保存邮箱级回执，不伪造任务投递。迟到送达、移除抑制事件、重订、新活动和续发都不清除本地拒发；不做打开/点击跟踪。

绑定、反馈、首次拒发及脱敏审计用原锁和事务保证。签名入口审计是系统来源，不冒充员工；记录不保存原始正文、签名、密钥或诊断文本。已开始尝试仍按原守卫记录结果，新尝试/重试继续拒发。旧权限、只读、预算/冷却、限速、邮件优先及单封确认/主动资料邮件规则不变。未开放真实发件、账号、费用、隧道、公网接入或部署。

新增SUBSCRIPTION_FEEDBACK_ENABLED=false及空SUBSCRIPTION_FEEDBACK_SIGNING_SECRET示例配置，不修改已有.env。新增私有邮件绑定集合，反馈支持来源摘要和邮箱级抑制，附20261126_090000_subscription_signed_feedback迁移与生成类型。只在独立随机库应用，原演示库未升级；需要接入前先备份数据库与图片、停Web/worker、迁移并重建，勿local:reset。

开发者已跑通真实HTTP调用实际POST处理函数→私有绑定→回执/拒发→资格/新冻结/续发/worker的隔离模拟，签名密钥随机生成，邮箱和资料均虚构，不连接供应商。独立复核的重要问题已一轮修正：非永久退信兼容；worker先证明另一活动未尝试任务确实可调度，再验证签名拒发后不领取/尝试且全表不变；首见消息ID错误归属和误导字段均按绑定验证。修正后完整检查551/551、38组订阅集成退出0，lint0错误/445既有警告、831文件行长合格。精确CI结果见[PR118](https://github.com/yaemart/huacompanion-ai/pull/118)和[交接记录](handoff.md)。无新增页面，无页面截图或真人/真实投递验收。
