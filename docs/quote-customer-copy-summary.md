# 客户版报价说明

管理员在「内容中心 → 公开公司信息」维护合作对接、华伴统筹和代收三段客户版说明。中英文入口共用这三段文字，留空使用方案中的默认文案。代收项仅显示代收说明。实际服务方与第三方收款方不同时，以费用项明确列出的三方名称为准。

送审时，主管在每个费用项下看到准备给客户看的说明。发出前，如果某个费用项适用的说明已变化，运营须重新送审。发出后，旧版继续显示发出时的说明，即使新版替代了它。

## E7、E8 亲测

1. **E7。** 管理员填写一段虚构的统筹说明。用运营在演示服务单里新建一份含华伴自营项的报价，补齐主体、保存并送审。
2. **E8。** 换主管核对费用项下的「客户版说明」并批准。管理员再改这段说明。运营刷新后应看到「对客报价说明已更新，请重新提交审核」，重新送审、经主管批准后再发出。
3. 发出后再次修改设置，刷新业务工作台，核对已发出版本仍保留原文。已关联虚构客户且启用客户中心的隔离演示站，也可用客户身份核对同一版本。代收专用说明已在隔离库验证。

合并后，已有演示库须先停站并配套备份数据库和图片，再由开发者应用并登记 `20261113_120000_quote_customer_copy`，之后按原命令启动。没有新增环境变量。 [本地测试指南](local-testing-guide.md)
