# 报价模板：本地验收

管理员在[后台](http://127.0.0.1:3100/admin)的“业务运营 → 报价模板”维护三项对客文字：
包含项目、不包含项目、变更与取消规则。每个服务类型一份，停用后重新打开报价页不再出现。
没有预置模板，验收请填虚构文字。

1. 管理员为“展会与商务访问”新增一份虚构模板，勾选“供新报价使用”并保存。
2. 运营打开[报价与履约](http://127.0.0.1:3100/business-center)中权限内的展会服务单，展开“新建报价版本”。
   先手写一项，选模板并点“填入模板”。确认其余空字段填入、手写文字保留，三项仍可修改。
3. 按北京时间填写未来到期日期，保存草稿。打开新服务单，确认不会带入上一单未保存的报价文字。
   修改或停用模板，原报价草稿和历史版本保持原文与原到期时刻。

模板不提供定价或代收建议，也不会发出报价。报价分项、经营主体和所有报价二审仍属任务 F。
本批可验收 E7 中的报价预填和有效期；完整 E7/E8、无指导新人计时及实体手机验收仍未完成。

本机 3100 已升级，可直接刷新使用，不用 reset。其他电脑的旧演示库先配套备份数据库和图片，
核对后只执行 `20261111_100000_quote_templates` 增量；无需新环境变量或依赖。新库走完整迁移。
