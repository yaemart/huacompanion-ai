# 今日待办 · E10 亲测

合并后重启本地演示站。手机与 Mac 连到同一个可信 Wi-Fi，临时用 `npm run local:start -- --lan` 启动，在手机打开终端显示的私网地址加 `/admin`。用完恢复普通启动。 [同 Wi-Fi 操作与注意事项](local-testing-guide.md#临时用同一wi-fi手机访问)

1. 用演示运营账号登录。从登录成功开始计时，确认首页显示「今日待办」，一分钟内说出下一步要做什么。
2. 点「查看并处理新咨询 · DEMO-INQUIRY-1」或今天到期的 `DEMO-INQUIRY-2`。写一条虚构内部跟进，把新咨询状态改为「处理中」，并把「下次跟进」设到北京时间明天或以后，保存。回到后台首页刷新，确认这项退出今日清单。如果测试数据已处理完，可在自己负责的演示咨询上先设一个今天的跟进时间。
3. 用新人账号打开首页，确认看不到运营的咨询。用审核人账号可打开授权板块内待审核的指南或政策。主管可打开权限内待审核报价的对应版本。

待办按北京时间的截止时间排列，逾期项保留。无截止事项按进入队列的时间排。审批由当前角色、板块、团队和禁止自审规则决定；已分派复核待办来自现有通知与待办流程。登记内容复核后，可回到原待办标记完成。已生成的政策到期提醒可提前处理。

本批无新增迁移或环境变量。已有演示库如果还缺 PR #57 的报价文案迁移，先按启动提示备份并升级。实体手机和新人计时由验收者记录。
