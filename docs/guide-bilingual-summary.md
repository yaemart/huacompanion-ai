# 来华指南双语对照本地验收

用运营账号打开[内容工作台](http://127.0.0.1:3100/content-center?kind=guide)，按 E6 操作。

1. 打开一份已保存的虚构中文指南，点「添加英文版」。桌面左边看原文，右边写译文。手机可点「展开原文」。已有译文时，点「打开英文版」。
2. 核对板块、排序和来源已带入。填写英文标题及正文，按需要补摘要。系统会沿用内容标识，并按英文标题生成网址。
3. 点击「保存草稿」，再点「提交已保存稿审核」。确认英文版进入待审核，返回原稿时中文版仍保持原状态。
4. 如提示原稿更新，点击「读取最新原文」，核对左侧后再保存。右侧已经写好的译文会保留。

开发者用 E5 的 769 字虚构中文指南完成以上流程，并验证了英文原稿可反向添加中文版。保存后重新打开英文版仍是同一份稿件。390 像素视口通过原文展开和收起检查，真人新同事独立计时与实体手机仍待实测。

本轮入口用于来华指南。其他电脑同步后普通重启即可，无需迁移或重置数据。
