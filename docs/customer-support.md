# 华伴首批客服系统

## 本地入口与操作

- 客户：`/zh/support`，将 zh 换为 en/es/fr/de/it/ar 可切换界面语言。全站导航已有“华伴客服”。
- 员工：`/support-center`，先使用现有管理员、经理或客户运营账号登录。
- 原始记录：后台“客户服务”分组；直接改写受限制，处理操作通过客服工作台进行。

客户可以创建会话、留言、要求人工接管，或选择展会商务／家政需求表单。AI 建议只预填允许的服务字段，客户仍需核对、补充身份与同意后提交。每次确认使用固定请求编号防止重复建单。客户只能读取本浏览器凭证授权的会话；邮箱、姓名和咨询编号不能用来查他人记录。凭证有效期 30 天，清理浏览器后需人工核实历史问题。

管理员处理未分配队列并分团队。经理在本团队分配运营负责人；运营只处理本团队本人负责会话。客户在会话已分配后提交的新咨询继承同一团队和负责人。人工回复自动接管；内部备注不发给客户；跟进时间当前以 UTC 录入。客户再次留言会重新打开已解决会话。实际报价、预约及售后更新通过关联咨询后台处理。

编辑／审核角色没有客服权限。客户资料不会因为同邮箱而自动合并。跨设备认证、外部渠道、附件、支付和自动派单不在首批。

## AI 当前状态与启动

代码包含真实持久化任务处理和可替换的 HTTPS 模型网关适配器；本地尚未配置外部模型，**没有声称真实模型已接通**。未配置时客户仍可留言及建单，显示人工待接手，不生成假 AI 答复，不宣称员工实时在线。

网关配置均放在服务端环境变量中：

- `SUPPORT_AI_ENDPOINT`：自有或受信任网关 HTTPS 地址；不是未经适配的任意模型厂商接口。
- `SUPPORT_AI_KEY`：网关密钥，不放前端，不提交 Git。
- `SUPPORT_AI_MODEL`：网关识别的模型标识。
- `SUPPORT_AI_DAILY_TOKENS`：每日 UTC 的全局预留令牌上限；必须是正整数，否则不调用。
- `SUPPORT_AI_CONVERSATION_TOKENS`：会话累计预留额度，默认 100000。

选择实际模型供应商后，应实现下述网关契约或替换 `configuredAdapter`，通过真实模型验收后启用。供应商的数据处理方式和对客告知需先明确。本轮没有向任何外部模型传输对话或发生模型费用。

`npm run support:worker` 启动独立工作进程；`npm run support:worker -- --once` 处理一次轮询，用于检查。网站与 worker 必须同时运行，不能依赖客户页面驱动任务；Replit／云端需要为 worker 配置持续进程或调度。当前前台每 5 秒轮询。

网关接收 POST JSON：

```json
{"model":"configured-model","input":{"locale":"en","topic":"housekeeping","instructions":"...","history":[{"role":"user","text":"..."}],"sources":[{"id":"service:service-housekeeping","revision":1,"title":"...","url":"/en/services/housekeeping","text":"..."}],"requestDraftAllowedFields":["city","homeService"]},"maxOutputTokens":2000}
```

请求头使用 `Authorization: Bearer ...`。返回结构：

```json
{"reply":"...","sourceIds":["service:service-housekeeping"],"summary":"...","requestDraft":{"homeService":"regular"},"handoff":false,"usage":{"inputTokens":100,"outputTokens":40}}
```

`summary`、`requestDraft`、`handoff` 可选；字段仍受服务器白名单、长度和来源检查。翻译任务的 input.task 为 `{kind:"translate",targetLocale:"zh"}`，只翻译对应客户消息，sourceIds 为空；输出仅保存为员工内部译文。客户必须允许 AI 处理，员工才可请求翻译。

## 模型边界与运行限制

AI 只使用审核发布资料和受限的客户文字。内部备注、员工回复、客户档案、正式表单及详细工单不发给模型；发送前再次检查资料可用性，发布版本变更时拒绝旧答复。

首批采用保守外发边界：出现数字、联系方式或地址／门禁／证件关键词的客户文字会转人工，整个相关历史不发送模型。**日期、金额、面积等也可能触发该规则**，可改在结构化需求表单中填写。该规则不是完整的个人信息识别器；接真实模型前应结合供应商政策和实际样本继续验证，不能宣称能识别所有敏感表达。

全局额度采用输入 UTF-8 字节数加输出上限预留，不等同真实费用；超时或进程中断不自动重复付费调用。超时 60 秒，租约 120 秒；失效租约转人工。人工接管、客户新消息及语言变更会阻止过期结果发送；内部备注、分配和跟进时间不会打断有效回答。

每会话最多 900 条消息、每分钟最多 12 条客户消息、最多 20 个确认需求；同一访客最多 100 个会话，全站每 10 分钟最多新建 100 个会话。部署公网前还需网关级速率限制。员工列表首批展示最近 200 个权限内会话，客户展示最近 100 个；大规模使用需分页检索升级。
