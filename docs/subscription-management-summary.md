# 本地亲测 · 订阅管理

管理员登录后台后可从「订阅管理」查看各主题的待确认、已订阅和已退订数量。下方列表按主题和状态筛选，每页 25 条，日期按北京时间显示。每条记录代表一个邮箱对一个主题的订阅，同一邮箱订阅两个主题计两条。

统计表显示全部主题的当前数量，筛选只作用于下方名单。列表显示邮箱、主题、语言、状态及申请、确认、退订日期。需要停止接收新申请时，管理员仍可查看已有订阅。

## 亲测步骤

1. 启动 `npm run demo`，再开终端执行 `npm run test:subscriptions -- --preview`。打开终端提示的本次预览账号文件，获取临时管理员与运营账号，密码在预览关闭后失效。
2. 在 [3186 后台](http://127.0.0.1:3186/admin)登录临时管理员，点「订阅管理」。预览有 28 条虚构订阅，应显示两页；点下一页查看剩余三条。
3. 筛选「政策更新」和「已订阅」，应显示四条。上方统计表仍列出各主题的全部数量。可用手机尺寸检查名单在自己的区域横向滚动。
4. 退出并登录临时运营账号，应看不到订阅管理入口；直接访问管理页需管理员登录，访问名单接口会被拒绝。按 Ctrl+C 清理临时数据库和账号文件。

`npm run test:subscriptions` 可重复验证管理员权限、筛选、分页、并发读取及账号撤权后的拒绝行为。本批提供只读管理，CSV 导出在下一批，群发继续留在停止点 C。
