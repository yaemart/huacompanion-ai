# 本地活动永久取消：本轮亲测

本批先完成取消服务和“已取消”的页面状态，尚未增加取消按钮。获独立主题授权的主管只能取消本人当前活动，原因必填；没有有效模拟确认、已经暂停或来源下架时仍可取消。取消后不能恢复，换成同一活动的新版本也不能继续处理。

## 怎么亲测

使用 Node24.22.1，保持本机演示 PostgreSQL 运行，在项目目录执行：

```sh
npm run test:subscriptions
```

脚本新建随机测试库，应用迁移、准备虚构活动并运行24组测试，最后自动清理。无需关闭原3100站点、重置原演示数据或手动操作数据库。最后应看到：

```text
PASS 本地活动永久取消、权限与终态、历史和额度保留、完成竞争、迁移保护及审计回滚
```

这条测试实际检查：

- 普通运营、未获授权的管理员、其他主管、已撤权账号、旧版本和非本地环境不能取消；空原因、过长原因及额外身份字段被拒绝。
- 重复取消保留第一次的时间和原因，不重复记审计；原暂停记录保留。
- 已经完成的模拟任务和已有资格取消原因保持原样；未完成任务取消，有效领取凭证到期。取消与另一个进程提交完成同时发生时，先取消会拒绝旧凭证。
- 原快照人数、已占份额和余额不改写；取消后不能冻结、再占份额、领取、提交完成或恢复。后续退订和资格复核也不改写完成历史。
- 审计提交失败时，活动状态、任务和租约全部回滚；有取消数据时拒绝回退迁移。

页面渲染回归检查“已取消”、原因及不能恢复的说明；有无历史快照时都不再出现模拟确认、恢复或冻结操作引导，历史快照保留，资料修改禁用。本批没有新增取消入口，也未声称完成真人或浏览器取消按钮验收；按钮与交互将在后批实现。发现失败时请记录时间、命令和最后错误文字，不附密码、邮箱名单或领取凭证。
