# 本页自动挑选并领取本地模拟任务

获独立主题授权的主管，可在本人已确认并冻结的活动中开启“本页自动领取”。页面每5秒选择一项可领取的已占位任务，再调用原领取接口；开始尝试和结果仍由人手动操作，不发送邮件。关闭、刷新或离开会停止后续调度，在途领取仍可能完成，不等于独立后台worker。

## 怎么亲测

使用Node24.22.1。管理员设置虚构余额并授权，主管保存、生成双语模拟并确认、冻结名单，然后准备若干占位。打开“本地模拟任务演练”，点“开启本页自动领取”，等待候选领取后手动开始并记录结果。

持有凭证时不会自动改领或开始。临时失败/429仍等原退避；等待期间可领取其他可处理任务。完成、永久失败、待核对、已开始后租约到期、五次/23小时门槛及当前失去资格者均跳过，没有清除待核对入口。候选不是抢占保证，原领取会重新核验权限/资格和并发租约。原余额/营销额度/正文/唯一键规则保持。

任何选择或领取错误停止自动模式；领取回执不明时保留原任务与输入、锁住其他写入，只能核实原操作，不重新挑任务。核实返回已占用不会取回凭证；未开始的租约到期可重领，已开始过期仍待核对。状态汇总需手动刷新，有自己的统计时间。
