# 月报 CSV · 本地亲测

从后台首页打开「个人业绩与月报」，选月份后点「查看月报」，再导出页面当前显示的报表。文件名为 `staff-monthly-YYYY-MM.csv`，Excel 可直接打开中文。

1. **运营或主管**。选一个月份，点击「导出当前月报 CSV」。核对员工编号、姓名和月份只有本人。列「统计截至时间（北京时间）」带 `+08:00`。若当前处于试行月份，「月报模式」为「试行观察」，只显示指标、样本、目标及状态。
2. **待定记录**。登记一条虚构投诉后导出，查找对应记录编号。确认个人归属后重导，应从「待确认」变为「申诉期内」。申诉后为「申诉待复核」。若跨月结案，重新导出首次确认月，核对更新后的指标、复核状态和新的统计截至时间。
3. **管理员**。选择「全部员工」，点击「导出全员月报 CSV」，按员工编号筛选，检查逐人数据。再选一名员工点「查看月报」，导出后应只剩该员工。全员文件保留已停用员工的历史数据。
4. **审计**。管理员打开「后台 → 操作记录」，查 `staff-monthly-performance` 的 `csv-export`。每次文件生成记录导出账号、时间、月份、员工范围、员工数及数据行数。数据行数包含指标、待定及复核更新，表头不计。

导出复用月报权限和状态。姓名等文本按共享规则防公式注入。试行导出不生成分数。凭据原文、客户联系方式和内部备注保留在各自授权页面。新批次无迁移、配置、依赖或种子变化，沿用 PR66 数据库版本。
