# 本地亲测：展会、服务项目、机构的填写示例和模板

在内容中心，中文稿和英文稿的标题、摘要及对应业务说明字段旁有虚构示例。中文／当地语言地址与英文地址各有格式示例。空白的观众说明、服务流程、机构预约等字段可选择「插入模板」，然后用已核实的内容替换〔括号〕里的文字。替换完成前，编辑和审核页面的字段旁会显示提示。发布前由审核人按原流程核对内容。

## 合并后亲测

在本机同步 `main`，运行 `npm run demo:stop` 和 `npm run demo`，用运营或内容编辑演示账号进入内容中心。请使用虚构资料。

1. **展会。** 打开虚构展会，查看场馆和地址的填写示例。保留已有展品说明，在空白的「适合观众」插入模板并补齐，保存后刷新核对两项。
2. **服务项目。** 打开英文项目，在「服务流程」插入英文模板并补齐，检查「包含项目」原有内容仍在。家政项目还可查看服务范围、收费及售后说明的示例。
3. **机构。** 在「预约方式与条件」插入模板并补齐。查看「公开资质核验说明」的格式示例，有关资质请按录入的虚构官方资料写。给「资料来源」填核实日期。
4. **预览和送审。** 打开「预览已保存草稿」，确认只展示保存的文字。送审后再回到编辑页，检查待审核稿的字段和保存按钮已锁定。

本轮用隔离演示库和 Chrome 的手机及桌面视口跑过三种稿件。实体手机和新人独立计时留给本地验收。
