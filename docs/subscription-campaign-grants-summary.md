# 本地亲测 · 群发 B1 独立授权基础

你已于 2026-11-20 选择 B 及默认规则。第一批先把授权基础做好，后续再逐批接活动编辑、预览、模拟测试和发送调度。

本批只允许服务器授权服务设置“政策更新”操作权。有效管理员授予或撤销，主管（含兼任主管）须有显式授权；管理员自己也不会自动获群发操作权。授权后仍看不到订阅邮箱名单、不能导出名单。重复设置不产生新权限版本，撤销、重新授予会递增版本，供后续活动识别旧确认。

## 现在怎么测

原演示数据库已运行时，用 Node 24.22.1 在项目目录执行：

```sh
npm run test:subscriptions
```

它会新建独立临时库、应用迁移、运行 12 组测试并清理临时数据，无需 `local:reset`，不改变原演示账号或资料。除原十组订阅回归外，应看到：

- `PASS 群发授权私有集合、默认关闭、唯一约束和迁移回退保护`
- `PASS 群发独立授权、版本撤销、当前角色、审计原子性、并发停用和邮箱权限隔离`

其中包括：普通运营/编辑/审核员拒绝，伪造角色和旧权限拒绝，主管授权后仍不能读/导出名单，8 个并发设置只保留一条授权，停用账号优先于等待中的授权，以及审计提交失败时授权不生效。
