# 本地编辑体验：第一批

咨询和服务商申请的初始资料改成中文只读卡片，原来保存的 JSON 内容不变。已知选项显示中文，自由文本保持客户原话；旧未知字段保留并提示“其他资料”。家政初始资料也使用卡片。

处理操作放在编辑页顶部，来源、语言、编号、隐私记录、团队等放入“提交来源与管理信息”折叠区；团队仍仅管理员可改，服务商状态与公开许可仍保持本批之前的权限。没有改数据库、种子或真实外部服务开关，不需要重置数据。

本批只做 E P0 第1条的前两项。跟进记录仍是原来的备注，尚未变追加时间线；转服务单按钮、主管服务商审核、标准多选、报价模板、内容整篇编辑与对照翻译等继续按顺序做。状态联动另见待确认方案，不在本批实施。

亲测入口：启动本地演示，运营登录后从“客户咨询”打开自己负责的演示咨询；管理员可查看服务商申请。对照清单 E7 的“看懂客户需求”部分、E9 的“看懂申请”部分。无需 local:reset；完整 E7、E8、E9 仍未完成，新人10分钟测试不能记为通过。

实际测试和截图进度见 PR、docs/progress.md；开发者模拟视口不等同于实体手机或新人无指导验收。
