# 服务商语言与区域：标准多选

服务商申请编辑页的“支持语言”“服务区域”现在可以直接勾选。名单复用系统已有的
七种语言、八个城市，不需要记代码或手写逗号。原代码、中英文及现有目录的其他语言名称
会自动对应勾选；例如English会选中英文，Shanghai会选中上海。

无法识别的旧内容会显示“待人工核对”，默认保留。只有确认旧值不适用时才点“已核对，
移除旧值”。名单里没有的语言／地区请留待核对并反馈管理员，不能猜成其他选项。
打开页面或只改联系人不会自动改写旧值；修改多选并保存后，相关字段按中文名称保存，
未移除的旧值也保留。原申请详情、旧备注和历史版本不变。

本批没有扩大主管权限，不会因选择语言／区域就核实服务商或允许其公开展示。
主管“核实通过／签约／暂停”按钮、原因与审计紧接着下一批独立PR；所以E9完整审核还未完成。
