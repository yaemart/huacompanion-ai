# 本地模拟活动暂停与恢复：亲测指南

本批先完成服务和测试，没有新增后台按钮或常驻进程。获授权主管只能暂停/恢复自己的活动；真实邮件继续关闭。暂停不删除历史，不归还或重复占用模拟份额。

## 怎么亲测

保持本机演示 PostgreSQL 运行，使用 Node24.22.1，在项目目录执行：

```sh
npm run test:subscriptions
```

脚本创建随机临时库，应用迁移、运行22组虚构测试，最后清理测试库和子进程。无需手动改原库、暂停网站或重置3100演示。成功时最后看到：

```text
PASS 本地活动暂停恢复、跨进程完成竞争、旧租约失效、版本与确认门禁、权限及审计回滚
```

本批自动验证：

- 默认未暂停；状态变化需要原因并记录操作者、数据库时间和失效租约数量。重复点击同一状态不重复记录，也不覆盖原原因。
- 即使没有有效模拟确认、发件配置变了或政策来源下架，仍然可以暂停。恢复必须有当前有效的模拟确认。
- 暂停后不能冻结名单、新占份额、取得租约或提交完成。子进程与父进程争锁时，独立连接确认真实的两层等待关系后才放行；先提交暂停后，子进程完成被拒绝。
- 暂停让尚未完成的有效租约到期；恢复不复活旧凭证，必须重新抢占。已经完成的记录和原冻结人数保持不变。
- 暂停按同一活动编号持续，保存新版本不能绕过；旧版本写入和他人操作被拒绝。
- 审计提交失败时，状态和租约修改全部回滚；普通运营、无单独授权的管理员、跨主管和非本地操作被拒绝。原单封邮件队列不变。

发现失败时请记录命令、时间和最后错误文字或截图，不附 `.env`、密码或租约凭证。本轮没有浏览器/真人手机验收，不把自动测试视作运营人员已亲测。

## 数据和后续

新增一张私有活动控制表，无记录时沿用未暂停行为；有记录时拒绝回退迁移，避免丢失暂停历史。迁移只应用随机测试库，原3100/55442、图片及种子保留。原库升级前仍需数据库与图片配套备份、迁移并重启进程；无新环境变量或依赖。

填写原因及同状态不改历史是本批的审计输入选择；若原因写错，不能用重复点击覆盖旧记录。暂停中的未完成工作恢复后需要新租约，已完成工作不会重做。本批不撤回任何外部操作，也不赋予真实发送资格。

后台控制按钮、永久取消、重试/待核对、共用尝试与冷却、全站限速/优先级、真实余额及投递回执仍待后续。真实邮件、AI、语音、通话和正式评分保持关闭；原始日志仅在本机忽略目录。
