# 同一活动本地续发：后台入口

PR113 的本地服务现已接入政策群发草稿页。负责人保存同一活动的新版，重新生成模拟邮件、逐语言确认后，勾选范围确认并点击“提交本版续发（不发送）”。只处理原名单中从未尝试且仍合资格的虚构邮箱任务；原快照、已尝试、已取消和待核对记录保留。

提交后显示本版已保存的范围与时间，重开页面即可继续使用现有占位和领取演练。历史收据不代表当前执行获准；来源、确认、权限、暂停取消及原额度、预算、限速、邮件优先和重试守卫仍然检查。没有真实发送、清除或强制重试，也不会自动启动 worker。

网络失败或回执不完整时，页面锁住其他写入并保留政策选择。只能点击“只读核实本版续发”：已提交则原页显示收据并继续锁定，明确点击“重新打开本版活动”后才核对当前条件；无记录则解除锁定，要求重新勾选，不会自动再提交。接口同时要求本人当前授权、同源 JSON 与明确确认。

开发自测使用隔离生产副本、随机库和虚构主管。32 项原任务中，一项待核对、一项取消；第二版续发30项，模拟完成一项后，第三、第四版各续发29项。模拟“服务未收到请求”和“已提交但回执丢失”均按上述流程恢复，原历史逐项不变。390视口无横向溢出，提交按钮50像素；控制台无错误，验收后已登出、恢复视口并清理预览。独立复核后另建最终隔离生产预览：设置变化后只读找回收据，全表指纹不变；明确重开后才出现一次原有确认失效重置。导航期间持续锁定到旧页卸载，避免慢重开丢失选择。

可亲测流程：保存改版 → 本版模拟及双语确认 → 勾选续发范围 → 提交 → 原未尝试任务准备占位 → 领取、开始和记录模拟结果。修改选择尚未保存、暂停取消或结果未核实时，相关按钮会禁用。无需 local:reset。

本批无新迁移、环境变量或依赖；原3100演示站和55442原库没有升级。原站若尚未应用PR113，须先备份并停止Web/worker，应用其已合并迁移、重建后再测，不能把当前旧演示页当成本批版本。完整测试与独立复核结果见[实施记录](progress.md)，PR114由用户决定合并。
