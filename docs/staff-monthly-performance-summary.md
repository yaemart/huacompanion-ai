# 个人业绩与月报 · 本地亲测

后台首页和「投诉、纠错与申诉」都有「个人业绩与月报」入口。默认打开北京时间当月，可切换到以前的月份。

1. **核对权限**。开 3100 演示站，用运营登录。打开「个人业绩与月报」，应只显示本人姓名，没有员工选择框。换主管登录也只显示本人。换管理员登录，先看「全员汇总」，再选择运营，核对与运营本人所见的指标一致。
2. **用虚构投诉测待定**。运营从自己负责的服务单登记投诉。在本月月报下方找这条编号，应显示「待确认」，有效投诉数暂缓增加。换未涉事主管确认华伴责任并归到该运营。运营刷新月报，应显示「申诉期内」。提交申诉后变为「申诉待复核」。
3. **核对结论和月份**。由另一位未涉事且有权限的人复核。维持判定会从待定移除，在最初确认的月份增加一次；撤销则移除待定并保持原计数。跨月复核后仍选择最初确认的月份核对。普通申诉窗口的截止边界由自动测试覆盖。
4. **核对日常指标**。咨询页设下次跟进时间，并用本人的运营账号追加带时间的跟进记录。到期后核对该月跟进率。送审一篇虚构指南，再用审核人退回或发布，审核人在自己月报查看处理次数和时长样本。

## 指标口径

- 首响按实际回复人或报价发出人及首响日期统计。有多条可能归属咨询的客服消息排除。按时跟进用咨询原定或及时改定的截止时间和员工追加记录，逾期后改期保留原逾期记录。
- 审核退回率以月内完成的内容、政策和报价审核为分母。只有能配对到送审事件才算审核时长。逾期复核以月末（当月为当前时点）仍未办结的已分配待办计数。
- 待确认按登记月显示；确认后按首次确认月挂账，复核结论更新该月。共用政策事实的双语纠错、全员汇总里的多人责任，同一事件各计一次。个人计数按本人的申诉状态计算。
- 内容目前缺少可核对的计划发布日期，所以「内容按计划发布数」显示「缺少计划数据」。暂无样本的比率和时长也会标明。评分与导出排在后续。
