# 本地亲测：草稿自动保存和离开提醒

## 这轮做了什么

内容工作台、政策共用事实和各语言公开说明会在有未保存修改时按 30 秒尝试保存草稿。正文可以继续编辑；保存完成后可以预览、重新打开草稿，或手动提交审核。已有正式版本继续按原流程审核发布。版本冲突会保留当前填写，页面会显示出错原因。

新报价、咨询和服务商的业务表单保留明确保存步骤。填写新报价后切换服务单或离开时会提醒；咨询和服务商使用后台已有的离开提醒。

## 合并后怎么测

用虚构数据启动 [本地演示站](http://127.0.0.1:3100/admin)，以运营账号登录。

1. **E5 指南自动保存。** 打开「内容工作台 → 来华指南」，新建草稿，填写标题并粘贴几段虚构正文。先别点保存，约 30 秒后应显示「草稿已自动保存」。继续编辑时正文光标应留在原处。刷新后核对标题与正文，状态仍为草稿。
2. **E1–E4 政策及送审。** 选一条虚构政策，修改内部核实备注，等自动保存后刷新核对。本语公开说明也可以同样测试。使用已填全的虚构草稿手动送审，确认待审核稿锁定，并用审核账号走退回和二审。
3. **离开提醒。** 修改指南摘要后立刻点「新建内容」、另一篇草稿或返回后台。先选「留在此页」，确认文字还在；再试一次并确认离开。已保存的草稿可直接离开。浏览器原生提示的文字由浏览器决定。
4. **冲突。** 同一账号开两个标签页编辑同一篇草稿。第一页改摘要，第二页先手动保存。等第一页自动保存时，核对其报出草稿已更新、输入还在。先复制需要保留的文字，再刷新核对第二页的版本。
5. **E7 报价离开提醒。** 在服务单「新建报价版本」中只改一项费用名称，然后点另一张服务单，选择留下并核对费用名称仍在。报价仍通过「保存新版本草稿」建立版本。

问题请在本地测试清单里记下场景编号、账号角色、操作步骤和截图。
