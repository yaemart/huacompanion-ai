# 后台报错提示 · 本地亲测

这批覆盖政策资料和说明、指南、咨询转服务单和报价。提示出现在操作按钮附近，写清要改的字段、资料来源顺序或费用项顺序。填错字段后可以保留其余填写，直接修正再试。报价审核、数据权限和保存规则照旧。

合并后重启 3100 演示站，用演示运营账号和虚构记录测试。本批没有迁移。已有演示库若还缺 PR #62 的每日摘要迁移，先按[上一批指南](staff-daily-digest-summary.md)备份升级。

| 清单      | 如何触发提示                                                                       | 应看到什么                                                                                        |
| --------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| E2 政策   | 新建虚构过境政策，先留空「适用口岸或区域条件」，保存草稿再送审                     | 提示在哪填、每行怎样填。补上虚构口岸、保存、重新送审后变成「待审核」                              |
| E5 指南   | 新建指南，先尝试空标题保存。填写标题后，添加一条来源并把网址写成 `example.invalid` | 先提示填标题，再提示哪条来源的「来源网址」需要完整网址。改为 `https://example.invalid` 后可以保存 |
| E7 服务单 | 打开自己负责且没有服务单的虚构咨询，清空「服务单名称」                             | 「转为服务单」旁提示先填写，并给出例子。填写后按钮可用                                            |
| E7 报价   | 填写虚构报价并添加第二项费用，把数量改为 0。修正数量后，把有效期选到过去           | 先提示「第 2 项费用的数量」，再提示有效期按北京时间选在将来。其它费用及条款保留                   |
| E8 审核   | 用有权审核的另一账号打开待审报价。留空审核意见，或打开含不同签约方和收款方的版本   | 按钮附近提示填写意见或逐项确认。原有禁止自审及管理员例外规则照旧                                  |

后台接口、浏览器和报价权限已在隔离库验证。完成一轮后，把触发提示的步骤、账号角色和截图记入测试清单。
